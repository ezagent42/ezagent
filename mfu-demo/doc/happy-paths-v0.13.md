# MFU 五方 Happy Path v0.13

> 日期：2026-07-23
> 基于 GDD v0.13 + 可试玩原型
> 目标：为 学生 / 院校 / 老师 / 孵化器 / 协会 五方各梳理一条完整的「理想用户体验流」

---

## 前置：五方在平台上的统一实体模型

GDD 对称性原则（D5/D27）：所有角色都是 AI-native 组织（Org），共享同一张面板。差异只在**禀赋**（初始解锁的能力供给）和**资质**（能解锁什么）。

```
Org = { 人（角色持有者）+ Agent（灵兽）+ Connector（接入能力）+ 资产 }
```

本文档中「学生」指 OPC 主理人角色，「老师」指运营工作室的老师角色——但他们是同一个「人」实体可以持有的不同角色（D20）。

## 1. 学生 Happy Path（OPC 主理人）

> 角色定位：从零开始经营一家 AI-native 公司，通过调教 Agent、路由决策、竞赛交付积累能力与信用，最终被真实孵化器选中入驻。

### Phase 1 — 注册与第一天（0–15 分钟）

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 1.1 | 打开平台，看到世界公开层（黄页、官网、游客模式） | 🌍 世界是公开的——未注册也能逛。首页展示活跃组织数、本周新命题数、孵化器入驻案例 | — |
| 1.2 | 决定注册 → 起公司名 → 选择所属学校（从已入驻院校列表中选） | 学校学籍自动绑定，算力配额 + 教练时长即刻到账 | 🏫 院校 |
| 1.3 | 个人助理（0 号 Agent / 小 H）首次对话：引导完成第一周规划 | 小 H 提示：「你的学校给了你 100 算力和每周 2 次教练咨询。先雇一个 AI 伙伴吧。」 | — |
| 1.4 | 从三种初始 Agent（设计/文案/增长）中选择第一个 | 花费 ¥2,200–2,600。Agent 随机附带一个性格特质（完美主义/卷王/夜猫子/话痨/佛系） | — |
| 1.5 | 接第一个练习单（学校命题，班内对抗） | 订单板展示 2–3 个练习单。难度 1，环节简单（strategy → design/copy → comm），奖金 ¥1,000–1,600 | 🏫 院校 |

**里程碑**：完成一次路由决策 + 交付确认，拿到第一笔竞赛奖金。

### Phase 2 — 调教与成长（第 1–4 周）

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 2.1 | 每周开始收到教练 Agent 的周复盘建议 | 教练指出：「你上周把策略环节全给了 Agent，但你的策略判断力比 Agent 高——下次考虑自己上。」 | 👩‍🏫 老师 |
| 2.2 | 在训练室或对话中调教 Agent（喂范例 / 写守则 / 复盘打回案例） | 资产 +1，能力分可见增长。Agent 在对话中说「老板，这个我练过！」 | — |
| 2.3 | 尝试不同的路由组合——发现某些环节「自己上」确实更好 | 判断力档案开始累积（路由正确率%）。适配星级从粗到细，标注不确定性 | — |
| 2.4 | 声望达到 30 → 获得白银认证 | 系统弹窗：「协会已颁发白银认证。你解锁了 DHS 预备营和协会会员的准入。」 | 🤝 协会 |
| 2.5 | 加入 DHS 预备营（免费会籍） | 算力 +40/周，孵化器真单解锁。孵化器的 Scouting Agent 开始追踪你的榜单数据 | 🏭 孵化器 |

**里程碑**：白银认证 + 预备营会籍。第一次接真单。

### Phase 3 — 真单与竞争（第 5–12 周）

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 3.1 | 接第一个孵器真单（竞赛制，4 队同题） | QA 门槛 62。准入规则由发单方自定义（可能要求白银 + 特定 Connector） | 🏭 孵化器 |
| 3.2 | 交付质量 ≥ 62 → 协会评审团盖章（S/A/B/C） | 获得真实评级。若未达标 → QA 打回，附具体原因 → 返工 → 产生复盘素材 | 🤝 协会 |
| 3.3 | 竞赛结果：排名、奖金、声望。落选作品进入题库（败者价值） | 即使是第 3 名仍有 20% 奖金 + 作品集收录。复盘素材 +1 | 🏭 🤝 |
| 3.4 | 持续真单交付 → 业务线案例数积累 → 业务树解锁新分支 | 例如：设计真单 ≥ 4 + 图像生成 Pro → 高端设计线解锁，出现高客单命题（¥15,000 级） | — |
| 3.5 | 声望 85 → 黄金认证 | 孵化器 Scouting Agent 将你标记为「重点关注」。官网展示黄金认证徽章 | 🤝 🏭 |

**里程碑**：黄金认证 + 稳定真单交付 + 至少一条业务线深度解锁。

### Phase 4 — 被看见与入驻（第 12 周+）

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 4.1 | 孵化器投后 Agent 发起第一次接触：「你的设计业务线 alpha 远超同层——愿不愿意接一个高难度命题试试？」 | 这是入驻前的能力验证——不是自动触发，而是孵化器人的真实判断 | 🏭 |
| 4.2 | 完成高难度命题（diff 4–5，奖金 ¥12,000–20,000）且获得 A 以上评级 | 孵化器正式发放入驻邀请（顶级会籍 offer）。包含：老厂房独立办公间、首笔孵化资金、注册真实公司的法务支持 | 🏭 |
| 4.3 | 接受入驻 → 关掉教学包装层 | Agent 训练资产、经营数据、主理人档案原样保留。同一套系统，继续真实经营。「不是迁移，是去掉包装」 | 🏭 |
| 4.4 | （可选）不接受入驻，继续在平台上经营多家公司 | 主理人可以同时是多家公司的角色持有者（D20）。孵化器邀请留在档案中，随时可接受 | — |

**终局状态**：入驻孵化器，注册真实公司。主理人档案永续——未来可用这份档案获得投资、跳槽、或再次创业。

### 岔路：破产路径

| 触发 | 流程 | 结果 |
|------|------|------|
| 现金 < 0 且无法通过桥贷/出售资产/打工回血 | 进入预警期 → 桥贷评估（孵化器）→ 紧急出售资产 → 若仍无法挽救 → 清算 | 主理人选择：① 出售资产重开（带档案 + 出售所得）② 被收购 ③ 休整（档案封存）。**信用/判断力/人脉/技能不清零** |

## 2. 院校 Happy Path

> 角色定位：平台的「基础设施供给方」+「教学效果受益方」。院校提供算力与教练时长，获取教改数据、可展示的实训成果、以及与孵化器对接的人才出口。

### Phase 1 — 入驻与配置（校方视角）

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 1.1 | 院校管理员（教务主任/实训中心负责人）注册组织账号 | 选择组织类型「院校」。填写基本信息：学校名称、院系、实训课程名称 | — |
| 1.2 | 配置算力配额方案 | 两种模式可选：① 按人头平均（每生 100/周）② 保底 + 竞争增量（每生 60 + 40 按表现分配）。教务 Agent 会根据历史数据推荐方案 | — |
| 1.3 | 接入算力集群（技术对接） | 通过 Connector 协议将学校推理集群接入平台。平台不做算力生产——只做配额路由与用量记录 | — |
| 1.4 | 配置教练时长方案 | 默认每生每周 2 次教练咨询。可选择使用学校自有的教练 Agent（由本校老师出品），或使用平台基础款教练 | 👩‍🏫 老师 |
| 1.5 | 发布本学期的练习命题（至少 3 道） | 命题走发单面板（与孵化器同一张面板，D27）。命题类型：设计/文案/增长。设置截止周数与评审标准 | — |

**里程碑**：算力已接通、命题已发布、学生开始注册。

### Phase 2 — 课程运行（学期中）

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 2.1 | 在教师控制台查看班级数据 | 可以看到（脱敏后）：每家公司声望、活跃度、订单完成率、路由判断力分布。**看不到**学生个人的财务细节和调教内容（隐私分层） | 🧑‍🎓 |
| 2.2 | 收到教务 Agent 周报 | 摘要：本周算力总消耗、命题完成率、QA 打回率 Top3 环节、学生整体薄弱点分布 | — |
| 2.3 | 根据数据调整命题难度或类型 | 例如：发现全班在「增长执行」环节打回率异常高 → 增发一组低难度增长练习单 → 或请教练 Agent 做专项辅导 | 👩‍🏫 |
| 2.4 | 学期中开放中期评审 | 协办/邀请协会评审员对优秀作品做中期点评。优秀作品进入协会案例库 | 🤝 协会 |
| 2.5 | 观察孵化器 Scouting 动态 | 看到「DHS 孵化器本周关注了贵校 3 家公司」——这是院校的对外展示指标之一 | 🏭 孵化器 |

**里程碑**：第一学期结束，收集到完整的实训数据。

### Phase 3 — 学期收尾与成果产出

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 3.1 | 学期末导出学习证据（Evidence of Learning） | 每生的档案摘要：完成了多少单、路由判断力变化曲线、Agent 资产增长、获得的认证。可作为课程成绩依据 | — |
| 3.2 | 获得教改数据报告 | 平台生成学期教学效果分析：哪些环节是系统性教学盲区、教练 Agent 的使用率与采纳率、竞赛制对学习动机的影响 | — |
| 3.3 | 优秀学生公司入驻孵化器的案例展示 | 学校官网（公开层）展示：「本学期 5 家公司获得孵化器入驻邀请」。这构成学校对外招生的实训成果证据 | 🏭 🧑‍🎓 |
| 3.4 | 决定下学期是否升级算力方案、更换教练 Agent 配置 | 基于数据优化。拥有多学期数据的学校，其「实训成果 / 算力投入」比率可被新生看到（选择学校的依据） | — |

**终局状态**：院校拥有持续增长的「实训成果数据集」+ 孵化器对接通道。学校成为学生选择创业课程时的重要参考（黄页可见）。

## 3. 老师 Happy Path

> 角色定位：教练 Agent 的出品方 + 学生的外部辅导者。老师通过调教自己的教练 Agent 来服务学生，以「带队指数」积累声誉，以 Agent 授权获得收入。老师本人也是一个 AI-native 组织的经营者。

### Phase 1 — 入场与工作室创立

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 1.1 | 老师注册组织账号，选择「工作室」类型 | 与学校的「教务主任」角色解耦——老师是独立的经营者。可绑定所属院校（但不必须） | 🏫 |
| 1.2 | 获得一个初始教练 Agent（平台基础款） | 与学生的初始 Agent 类似——教练 Agent 有自己的领域专长（策略诊断/文案指导/增长建议等），可以被调教 | — |
| 1.3 | 在训练室用**真实教学经验**调教教练 Agent | 喂入自己的教学案例、方法论、常见学生错误模式。这构成教练 Agent 的「自有资产」 | — |
| 1.4 | 发布教练服务（设置定价或参与学校免费时长池） | 两种模式：① 纳入学校免费时长池（学校为学生购买批量时长，老师按使用量分成）；② 市场定价（学生/其他 OPC 现金雇佣） | 🏫 🧑‍🎓 |
| 1.5 | 在学校课程中配置自己的教练 Agent | 老师通过学校面板指定「本学期课程默认教练为我的 Agent」。学校可配置多个可选教练（学生可切换） | 🏫 |

**里程碑**：教练 Agent 上线，开始有学生使用。

### Phase 2 — 带队与声誉积累

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 2.1 | 教练 Agent 开始提供周复盘与路由诊断 | 每次学生使用教练诊断，记录「诊断采纳后的结果」——这是带队指数的数据基础 | 🧑‍🎓 |
| 2.2 | 带队指数在达到最小样本门槛后公开 | 例如：带队 ≥ 5 家公司、覆盖 ≥ 2 个学期。指数显示为「alpha + 置信区间」 | — |
| 2.3 | 带队指数成为老师工作室的核心资产 | 黄页可查：「张老师 · 带队指数 +3.2（top 15%）· 覆盖赛道：设计/文案/增长」 | — |
| 2.4 | 受邀为协会出题或成为评审员 | 高带队指数的老师可能被协会邀请参与命题设计或评审——这是老师的角色资格成长 | 🤝 协会 |
| 2.5 | 持续迭代教练 Agent——通过复盘学生反馈、添加新的教学案例 | 教练 Agent 本身也在「被调教」中成长。老师的教练 Agent 会被版本管理（学生可看到教练 Agent 的迭代记录） | 🧑‍🎓 |

**里程碑**：带队指数达 top 20%，教练服务开始产生稳定授权收入。

### Phase 3 — 规模化与跨校影响

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 3.1 | 教练 Agent 被其他学校采购 | 不限于本校——平台上的任何学校都可以在教练市场中选择并采购 | 🏫 |
| 3.2 | 授权收入 = 教练时长使用量 × 分成比例 | 老师的知识以 Agent 资产形式规模化变现——突破了「一个老师只能同时带有限学生」的物理限制 | — |
| 3.3 | 带队指数跨校 alpha 排名 | 在所有学校的教练中排名，成为行业级影响力指标 | 🏫 |
| 3.4 | （可选）从工作室升级为「培训组织」——开始发自己的命题、培养其他教练 | 这是对称性原则的终极体现：老师工作室 → 培训组织 → 甚至可以成为孵化器的内容供给方 | 🏭 |

**终局状态**：老师拥有高带队指数、跨校授权收入、以及可交易的教练 Agent 资产。老师自己也是「人机协同经营」的活样板。

## 4. 孵化器 Happy Path

> 角色定位：真实商业需求的供给方 + 优秀企业的筛选者与投资人。孵化器通过命题发布、Scouting 监控、资金注入、入驻邀请，将平台上的优秀 OPC 转化为真实被投企业。

### Phase 1 — 入驻与禀赋配置

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 1.1 | 孵化器管理者注册组织账号 | 选择「孵化器」类型。填写基本信息：孵化器名称、关注赛道（设计/跨境电商/MCN/…）、投资阶段偏好 | — |
| 1.2 | 配置初始禀赋 | 设定：算力增量配给（会籍福利）、grant 总额度、桥贷利率与上限、入驻办公空间数量。这些构成孵化器会籍包的公开内容 | — |
| 1.3 | 调教 Scouting Agent | 设置关注条件：赛道、认证等级、特定业务线案例数、路由判断力阈值、地域/学校。Scouting Agent 将按这些条件持续扫描榜单与黄页 | — |
| 1.4 | 调教命题 Agent | 上传过往真实命题的 brief 模版。命题 Agent 帮助将商业需求转化为结构化的竞赛命题 | — |
| 1.5 | 发布首批真单（至少 2 个命题） | 走发单面板（与学校同一张面板，D27）。设置准入规则（认证、Connector、地域等）、奖金池、竞赛队数上限、截止周期 | 🧑‍🎓 |

**里程碑**：首批真单发布。Scouting Agent 开始追踪首批候选企业。

### Phase 2 — 筛选与投前（持续运营）

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 2.1 | 收到 Scouting Agent 周报 | 摘要：本周达到关注阈值的 OPC 列表、其关键指标（声望变化、最近 3 单评级、业务树解锁进展）、所在学校。按推荐优先级排序 | 🧑‍🎓 |
| 2.2 | 定向查看候选企业的公开信息 | 官网（作品集、认证、评级）、黄页档案、成长树位置。**看不到**内部财务和调教数据（公开/内部分层 D21） | 🧑‍🎓 |
| 2.3 | 对感兴趣的企业，通过命题设置更高门槛来验证 | 发一道定向邀请的命题（准入规则中指定邀请名单）。这是「软性尽调」——看企业在高难度真单中的表现 | 🧑‍🎓 |
| 2.4 | 发放 grant / 桥贷 | 对有潜力的企业发放小额 grant（¥3,000–10,000），观察资金使用效率与后续交付质量 | 🧑‍🎓 |
| 2.5 | 投后 Agent 记录每次互动的数据 | 命题完成质量、grant 后的表现变化、企业成长速度——构成内部的「入驻评估 dashboard」 | 🧑‍🎓 |

**里程碑**：识别出 3–5 家重点候选企业，完成至少一轮高难度命题验证。

### Phase 3 — 入驻决策与投后

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 3.1 | 孵化器管理者（人）做出入驻决策——不是系统自动触发 | 基于 Scouting 数据 + 高难度命题表现 + 主理人档案（判断力、信用、人脉），孵化器团队做出人的判断。系统不替人做投资决策 | 🧑‍🎓 |
| 3.2 | 发放入驻邀请（顶级会籍 offer） | 包含：老厂房办公空间、孵化资金条款、注册真实公司的法务与财务支持、Connector 生态接入 | 🧑‍🎓 |
| 3.3 | 企业接受入驻 → 在孵化器的「入驻管线」面板中出现 | 孵化器跟踪：企业注册进展、首月经营数据、Agent 资产迁移状态 | 🧑‍🎓 |
| 3.4 | 持续投后管理 | 投后 Agent 继续跟踪被投企业的经营数据。孵化器获得「入驻企业存活率」「6 个月营收增长」「下一轮融资率」等真实指标 | 🧑‍🎓 🏫 |
| 3.5 | 孵化器指标对外公开（部分） | 黄页展示：「DHS 孵化器 · 已入驻 12 家 · 存活率 83% · 专注设计/跨境电商赛道」。这构成孵化器的品牌资产——吸引更多学校合作和更多优质 OPC 申请 | 🏫 🧑‍🎓 |

**终局状态**：孵化器在平台上建立了稳定的「命题 → 筛选 → 入驻 → 投后」管线。入驻企业的成功案例反哺孵化器品牌，吸引更高水平的学生和命题。

## 5. 协会 Happy Path

> 角色定位：行业标准制定者 + 质量评判者 + 行业资源连接器。协会通过认证体系、评审服务、命题发布和案例库运营，在平台上建立标准话语权。

### Phase 1 — 入驻与标准建设

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 1.1 | 协会秘书处注册组织账号 | 选择「协会」类型。填写：协会名称、行业领域（设计/跨境电商/数字营销/…）、认证体系名称 | — |
| 1.2 | 设计认证等级与标准 | 设置认证层级（例如青铜/白银/黄金三级）及每级门槛（声望、信用、真单评级记录的组合条件）。平台提供规则引擎，协会自定义具体参数 | — |
| 1.3 | 调教评审 Agent | 输入评审标准、常见缺陷模式、评分维度权重。评审 Agent 用于初评（所有真单交付物先过评审 Agent），人类专家再做抽查与终评 | — |
| 1.4 | 调教认证 Agent | 设定自动认证触发条件（达到门槛自动获证）vs 人工审核条件（需协会专家复核）。认证 Agent 管理全部证书的发放/年审/吊销 | — |
| 1.5 | 发布首批行业命题 | 协会也有发单权（D24/对称性）。命题通常是对行业有示范价值的案例型命题（行业年会主视觉、白皮书文案等） | 🧑‍🎓 |

**里程碑**：认证体系上线。首批通过青铜认证的学生开始出现。

### Phase 2 — 评审与案例库运营

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 2.1 | 评审 Agent 对真单交付物进行初评 | 所有非练习单交付物自动路由到协会评审 Agent 初评。输出评级建议 + 评语。人类专家抽查（例如抽 20%） | 🧑‍🎓 |
| 2.2 | 协会专家团对争议性案例做人工终评 | S 级或边界案例触发人工评审流程。专家的评审记录本身也是资产——评审质量影响专家在平台上的评审员资格等级 | 👩‍🏫 |
| 2.3 | 协会案例库自动积累 | 所有真单交付物（含落选作品，脱敏后）进入案例库候选池。协会审核后上架 → 构成全平台的调教题库与行业参考 | 🧑‍🎓 🏫 |
| 2.4 | 认证 Agent 自动处理达到门槛的申请 | 学生达到白银/黄金门槛 → 自动颁发认证。争议案例（信用与声望不匹配、异常快速晋升）触发人工审核 | 🧑‍🎓 |
| 2.5 | 协会在季度评审报告中看到认证统计数据 | 摘要：本期获证企业数、认证等级分布、各校认证率比较、认证后企业真单表现追踪（认证的预测效度） | 🏫 |

**里程碑**：案例库上线、认证体系跑通至少一个完整学期。

### Phase 3 — 影响力扩张与标准演进

| 步骤 | 动作 | 系统反馈 | 涉及方 |
|------|------|----------|--------|
| 3.1 | 根据行业变化调整认证标准 | 例如：随着 AI 工具普及，设计类认证增加「AI 协同设计能力」维度。标准迭代是协会的核心竞争力 | — |
| 3.2 | 协会认证被孵化器引用为准入条件 | 「协会黄金认证」成为孵化器真单的常见准入条件 → 认证含金量提升 → 更多学生追求认证 → 协会话语权增强 | 🏭 🧑‍🎓 |
| 3.3 | 举办行业级命题竞赛 | 协会命题的奖金池可能来自行业赞助商。竞赛成果成为行业趋势报告的数据源 | 🏭 |
| 3.4 | 认证跨平台互认 | （远期）随着多个孵化器/学校/企业认可协会认证，认证成为 AI-native 从业者的「行业执照」 | 🏭 🏫 |
| 3.5 | 多个协会在平台上竞争 | 对称性原则允许存在多个协会（不同的行业、不同的标准体系）。企业可选择认证路径，协会之间竞争标准质量——优胜劣汰 | — |

**终局状态**：协会的认证体系成为行业基础设施。认证数据持续验证标准的预测效度。协会在平台上获得了持续的标准话语权与会员基础。

### 协会的商业模式（不同于其他四方）

与其他四方不同，协会的核心交换不是「资源 ↔ 交付」，而是「标准 ↔ 认可」：

- **收入**：会员会费（组织/个人）、认证费用、命题服务费（向发单方收取）、案例库授权费
- **支出**：评审 Agent 运行与维护、人类专家评审费、标准研究与迭代
- **核心资产**：认证体系的公信力（不可量化但最关键的资产）、案例库厚度、评审数据

## 五方交互全景：飞轮的运转

```
                    ┌──────────────────────────────────────┐
                    │                                       │
                    ▼                                       │
           🏫 院校                                         │
           算力+教练时长+题库                                │
           │                                               │
           ├──→ 🧑‍🎓 学生 OPC ──→ 🏭 孵化器                │
           │    调教Agent      入驻邀请                     │
           │    竞赛交付        grant/投资                   │
           │    积累声望                                    │
           │    │                                           │
           │    ├──→ 🤝 协会                                │
           │    │    认证+评审+案例库                        │
           │    │    标准话语权                              │
           │    │                                           │
           │    └──→ 👩‍🏫 老师                               │
           │         教练Agent+带队指数                      │
           │         授权收入                                │
           │                                               │
           └───────────────────────────────────────────────┘
```

### 理想飞轮的一次完整转动

1. **院校**提供算力与教练时长 → **学生**获得创业的基础设施
2. **老师**调教教练 Agent → 教练 Agent 指导学生 → 学生的路由判断力提升 → 老师的带队指数增长
3. **协会**提供认证标准 → 学生通过竞赛交付获得认证 → 认证成为孵化器筛选的参考指标
4. **孵化器**发布真单 → 学生接单竞争 → 优秀学生获得入驻邀请 → 入驻成功案例反哺孵化器品牌
5. **孵化器的成功**吸引更多学校合作 → 更多学校接入 → 更大规模的学生入口 → 循环加速
6. **协会的案例库**越积越厚 → 调教题库越用越强 → 学生 Agent 的平均质量提升 → 孵化器获得更高质量的入驻企业

### 飞轮的关键摩擦点（需要特别注意的设计细节）

1. **学生→孵化器**：孵化器的筛选是人做决策，不是系统自动匹配。这导致漏斗上端很大（Scouting 追踪数百家）但下端很窄（每学期实际入驻 3-5 家）。如何让「没被选中」的学生仍然觉得过程有价值？
2. **老师→学生**：老师的经济激励（带队指数 + 授权收入）是否会导致老师过度干预学生决策（「听我的就能赢」→ 削弱路由判断力的培养）？
3. **协会→孵化器**：协会认证被孵化器引用为准入条件 → 协会与孵化器之间可能出现利益捆绑（某孵化器只认某协会的认证）→ 平台需要反垄断机制？
4. **院校→学生**：院校是算力提供方 → 算力配额分配（均分 vs 竞争）是持续的政治张力。学生可能「择校」——选择算力更慷慨的学校。
