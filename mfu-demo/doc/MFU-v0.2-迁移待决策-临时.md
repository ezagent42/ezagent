# MFU v0.2 迁移待决策（临时）

> 用途：迁移 v0.15 时，凡是会改变游戏机制、概念边界或权限规则的内容，先记录，不擅自实现。
>
> 本文不是 living doc。全部功能迁移完成并由 ruihua 决策后，再把结论写回正式文档。

## 暂不实现

### T-01 认证与功能解锁

v0.15 使用青铜、白银、黄金认证，并把联合竞标、资产出租、公开评审与认证或成长树关联。

待决定：

- 这些功能由机构认证、MVO 认证、声望还是成长树解锁；
- 孵化器账号默认拥有哪些资质；
- 认证是准入条件、可信凭证，还是两者兼有。

本轮只展示已有认证徽章，不实现认证升级和权限门槛。

### T-02 MVO、人才与孵化器的成长结构

v0.15 的公司树和个人树包含已经过时的细分节点和认证节点。

待决定：

- MVO 如何从临时组织成长为 Organization；
- 孵化器是否拥有独立科技树；
- 人才能力采用怎样的通用层级；
- 哪些成长属于能力，哪些属于经验或认证。

本轮只保留等级、经验和“获得优化点”，不实现具体成长树。

### T-03 同题竞赛、排行榜与联合竞标

待决定：

- 它们是任务的特殊模式，还是独立入口；
- 比较对象是 MVO、孵化器还是学校；
- 评审由客户、协会、专家还是大众完成。

本轮只在任务档案中保留“普通任务 / 竞赛任务”字段，不实现对战。

### T-04 会籍与生态权限

v0.15 中学校、孵化器、协会通过会籍提供算力、订单、资金、教练和题库。

待决定：

- 孵化器作为玩家是否还需要加入其他孵化器会籍；
- 学校、协会和孵化器之间的资源结算；
- 退出、冷却和周费规则。

本轮生态页只展示合作关系和资源来源，不实现加入、退出和收费。

### T-05 学生打工与跨组织占用

待决定：

- 孵化器是否能主动把学生外派；
- 学生打工期间是否不能加入 MVO；
- 打工收入如何在学生和孵化器间分配。

本轮人才档案只展示外部经历，不提供“去打工”操作。

### T-06 世界时间与演示推进

正式系统时间与现实世界同步；Demo 需要快速展示运行结果。

待决定：

- 正式版的加速是否只存在于私人推演器；
- 客户演示版是否需要明确标注“演示推进”。

本轮继续使用“推进 1 天”，仅作为 Demo 操作。

### T-07 MVO 失败、解散与清算

待决定：

- 连续失败到什么程度会失去 MVO 身份；
- 解散后经验、组织图和认证如何保留；
- 人才、Agent、IP 和资金如何退回资源栏。

本轮实现风险和复盘，不实现强制解散。

### T-08 工具的归属与升级

待决定：

- 工具属于孵化器公共设施、单个 Agent，还是 MVO；
- 工具是购买、租用还是按次收费；
- 工具是否也拥有等级和训练记录。

本轮工具可以购买和配置，但不升级。

## 已明确、可以迁移

- 世界市场 → 世界 Tab；承接后才进入玩家的订单板。
- 订单板 → 左侧订单板。
- 进行中的项目 → 中央 MVO 的进行中的项目。
- 进行中的项目以组织图节点显示运行状态；外包以节点为单位发布为世界订单。
- 接单后的路由编排 → 创建新 MVO，不迁移旧路由 UI。
- 完整组织图工坊 → “孵化中的组织”内常驻入口。
- 办公室 → 办公室 Tab。
- 公司经营信息 → 分散到订单板、资源栏、待处理与单个 MVO 档案，不保留独立 ERP 面板。
- Agent 调教 → 资源栏的 Agent 详情。
- 交付确认、QA、复盘、升级、危机 → 右侧待处理。
- 成员、Agent、工具、IP、资金、算力 → 分类资源栏。
- 商店 → 资源栏中的“获取资源”。
- 客户、订单 → 订单板或 MVO 详情；财务、资产 → 资源栏或 MVO 详情；日志、官网 → MVO 详情。
- 创业教练 → 孵化器办公室。
- 个人助理 → 孵化器运营 Agent。
