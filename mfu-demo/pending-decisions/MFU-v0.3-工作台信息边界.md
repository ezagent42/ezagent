## P-01 办公室与资源栏存在内容重叠

当前“办公室”和底部“资源栏”都会展示或操作部分相同内容，例如人才、Agent、指导资源、资金、算力和运营状态。

需要后续判断：

- 办公室应该只表达玩家自身的经营目标、团队和运营活动，还是也承担资源管理；
- 人才、Agent、工具、IP、资金和算力是否全部以资源栏作为唯一操作入口；
- 办公室中哪些内容只是摘要，点击后应跳转到资源栏；
- 学校、企业、孵化器和学生的办公室是否应有不同功能边界。

在结论确定前，不继续向办公室增加新的资源操作。

## P-02 “运营 Agent 建议”与待处理存在内容重叠

当前办公室中的“运营 Agent 建议”会提示订单分配、风险和下一步操作；右侧“待处理”也承担需要玩家关注和作出决定的事项。

初步方向是将可执行、需要响应的运营建议放入“待处理”，但仍需判断：

- 哪些建议必须进入待处理；
- 哪些只是无需操作的观察或经营提示；
- Agent 建议应作为待处理事项本身，还是附在风险、验收、收款等事项中；
- 办公室是否还需要保留一块非强制的经营简报。

在结论确定前，保留 v0.3 当前界面，不迁移或删除现有内容。
