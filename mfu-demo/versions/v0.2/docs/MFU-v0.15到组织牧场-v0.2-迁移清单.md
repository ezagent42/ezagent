## 原 ERP 能力的最终位置

- 订单 → 左侧「订单板」
- 组织与项目 → 中央「孵化中的组织」及单个 MVO 详情
- 资产与采购 → 底部「资源栏」
- 财务与算力 → 「资源栏」中的资金、算力分类
- 决策与异常 → 右侧「待处理」

独立 ERP 面板已经移除。玩家不需要离开主要游戏画面，经营动作会直接改变这几个区域中的同一份数据。

## 订单的最终边界

- 市场订单 → `世界 / 订单市场`，当前玩家尚未承接；
- 已承接订单 → `我的工作台 / 订单板`，等待分配或正在履约；
- 节点外包 → MVO 在`进行中的项目`内把单个节点发布为市场订单；
- 外部节点成果 → 回到来源 MVO 的原节点，再继续原订单任务流。
