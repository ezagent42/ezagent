# MFU 多角色组织世界 v0.3

## 本版验证什么

v0.3 验证“一套游戏架构，多份角色档案”：

- 孵化器运营者、学校课程负责人、企业创新负责人和学生创业者看到相同的基本结构；
- 每个角色拥有独立的订单板、组织、资源、资金、算力和待处理事项；
- 四个角色共享订单市场、世界动态与公告；
- 角色差异由 `role-profiles/` 中的数据定义，不复制游戏页面和交互逻辑。

页面顶部的灰色角色控制器只服务 Demo 演示。正式产品将依据登录身份直接进入对应工作台。

## 共享与独立

共享世界：

- 公开订单；
- 节点外包订单；
- 世界动态；
- 新闻与公告。

角色独立：

- 已承接订单；
- MVO 与执行进度；
- 人才、Agent、工具、IP、算力和资金；
- 办公室、待处理、履约与成长记录。

## 世界筛选

世界订单按行业领域筛选，不按发布者身份分类：

- 推荐；
- 全部；
- 教育与校园；
- 消费与零售；
- 内容与品牌；
- 软件与 AI；
- 社会创新。

“节点外包”和“我发布的”是任务状态快捷筛选。

## 暂缓内容

长期组织、多重成员关系、跨组织调度权、成果归属和收入分配仍属于待决策范围。本版只允许相同的人物出现在不同角色视角中，不把这种展示定义为正式权限规则。
