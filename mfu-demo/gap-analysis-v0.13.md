# MFU v0.13 仿真差距分析

> 分析日期：2026-07-23
> 范围：GDD v0.13 + 可试玩原型 HTML

## 一、时间与节律

1. **世界时钟 vs 课堂节拍**：正式版锚定真实日历，但课堂 45 分钟需要完整的「接单→交付→评审」循环。推演器（沙盘）对新手无数据积累，精度为零。
2. **等待即教学**：真实创业中等待（客户反馈、评审、到账）是核心体验，原型将其压缩为「下一周」按钮。

## 二、Agent 系统

3. **Agent 能力的线性简化**：原型用 `cap * multiplier + rnd` 公式。真实 AI Agent 存在能力相变、幻觉、模型更新导致的 prompt 失效。
4. **调教无副作用**：错误调教只「不加资产」而不使 Agent 变差。真实 prompt 工程存在过拟合、负面迁移。
5. **Agent = 灵兽的法律真空**：基座模型归属权、客户数据隐私、AI 产出 IP 归属均未涉及。

## 三、订单与竞争

6. **订单过于确定**：固定环节、固定周期。真实订单有 scope creep、主观验收、中途取消。
7. **竞赛制 ≠ 主流商业形态**：多数真实订单是独家委托而非多队竞赛。落选仍有钱分（20%）在真实竞标中不存在。
8. **QA 阈值武断**：硬编码 62 分。真实世界中不同客户质量容忍度不同，同一客户在不同情境下也不同。

## 四、经济系统

9. **定价缺乏市场锚定**：所有价格（Agent、基座、教练时长）是人为常数，不随供需波动。
10. **缺失的财务维度**：无应收账款、应付账款、税务、汇率、通胀。
11. **「金钱不买能力」的内部矛盾**：基座模型直接提供质量乘数（×1.12/1.25），本质就是花钱买能力。

## 五、人的维度

12. **判断力的不可验证**：路由决策选了 A 就永远不知道 B 的结果。基准构造依赖「同难度」判定——这需要全知视角。
13. **情绪与关系缺失**：无创始人 burnout、团队冲突、道德困境、机会成本焦虑。
14. **多角色利益冲突**：D20 说人可同时在多家组织持有角色，但冲突检测在原型中完全不存在。

## 六、生态与组织

15. **孵化器筛选过于公式化**：真实孵化器有面试/路演/团队评估/赛道偏好/条款谈判，不是白银+信用≥70 就自动通过。
16. **学校的角色张力**：算力配额分配是政治问题；老师同时是教练 Agent 出品方（利益冲突）。
17. **认证的公信力**：认证通胀、认证套利、认证与市场脱节未建模。

## 七、技术与平台

18. **承载层不可见**：原型中 ezagent 完全不存在，所有数据在浏览器 JS 对象里。玩家无法感知「我已在真实系统上」。
19. **Connector = boolean**：能力接入被简化为 `true/false`，无技术摩擦、供应商竞争、计费复杂性。
20. **联机的黑暗面**：全平台联机带来的恶意行为、数据安全、策略推断在单机原型中不可见。

## 八、原型结构

21. **演示而非游戏**：无难度曲线、无失败学习循环、胜利条件自动触发缺乏叙事张力。
22. **不可归因的随机性**：对手分数完全随机生成，玩家无法从失败中提取因果知识。
23. **UI 先于机制**：大量界面是静态展示，核心教学循环（路由→调教→复盘）交互深度浅。

---

*注：以上多数问题在任何创业模拟游戏中都不得不做简化。此清单用于标记「知道我们在简化什么」，而非要求全部解决。*
