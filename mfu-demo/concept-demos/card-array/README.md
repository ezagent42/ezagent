# Card Array 协作阵列

Card Array 是一个独立的功能性教学 Demo，不是完整 MFU 游戏版本。

它帮助第一次接触平台的用户理解：

- 一个大订单如何被拆成多个位置；
- 玩家如何用本人和 Agent 卡牌完成自己的局部任务；
- 卡牌之间如何形成协作阵列；
- 局部成果如何进入完整交付；
- 玩家如何从完成小节点逐渐成长为能够组建组织的 OPC。
