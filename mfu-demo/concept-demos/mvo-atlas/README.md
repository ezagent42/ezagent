# MVO 图鉴 · MVO Atlas Concept Demo

这是一个面向孵化器、学校和企业负责人的概念试玩，用来验证 MFU 的核心爽点：

> 把已有的人才、Agent、工具和资金组成更多能工作的 MVO，并用真实订单证明它们的价值。

## 试玩目标

玩家在 3–5 分钟内完成一条闭环：

业务能力缺口 → 自由组建 MVO → 执行真实订单 → 分别获得经验与能力评价 → 可能发现 R / SR / SSR 特殊模板 → 承接更多业务。

## 概念边界

- **MVO 实例**：可以实际执行订单的组织，保存运行状态、订单履历和能力评价。
- **MVO 图鉴**：可复用的组织模板库，不包含具体人才、私有 Agent 或客户数据。
- **稀有度**：R / SR / SSR，只表示是否发现平台预先收录的特殊组织结构，不代表能力强弱。
- **经验**：完成过多少订单和留下多少履历，不自动等于能力提升。
- **能力**：根据客户验收、专家评价、作品质量和交付一致性形成的证据评价。

## 本轮实现范围

首版静态 demo 将包含：

1. 孵化器工作台与业务能力缺口；
2. 组织图工坊，支持拖拽资源到任务节点；
3. 一份真实产品验证订单的运行过程；
4. 经验、能力、稀有度三条独立结算信息；
5. 底部资源栏中的 MVO 图鉴，以及一键套用模板入口。

所有完整的组织图都可以执行。系统只展示结构差异和预估，不用“错误配方”阻止玩家。
