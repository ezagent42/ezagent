World UI redesign prototype

把 ezagent World UI 重组为聊天软件主界面

这个原型按完整功能覆盖重新组织：顶部保留 workspace 切换，顶层导航收敛为 Chat、Agents、Manage， Chat 成为默认工作台；Profile 进入用户菜单；设置类、工具类、系统类能力统一放入 Manage。

全局 Workspace Switcher Chat / Agents / Manage Session detail drawer User menu owns Profile CmdK visible entry removed
Coverage rule

不删除现有能力，只重排入口

sessions、agent config、workspace templates、socialware、plugins、Kanban、external mirror、SMTP、 caps、audit、routing 都被纳入新版 IA。

Recommended top-level IA: Chat / Agents / Manage
