系统解释

为什么不先让用户填 `project_cwd`

因为对普通 PM/运营来说，`project_cwd` 是宿主环境概念，不应该成为创建 Claude 助手的前置门槛。更成熟的做法是先提供托管/推荐模式，再把高级运行环境下沉给懂的人。
