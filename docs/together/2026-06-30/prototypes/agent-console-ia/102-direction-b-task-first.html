一个典型用户旅程

场景：PM 想给自己配一个 Claude 助手

  1. 进入首页，先看到“创建 Claude 助手”卡片
  2. 用模板/向导完成创建，不必先懂技术参数
  3. 系统引导把助手挂到当前 Session
  4. 只有当用户需要深配时，才进入详情页高级配置

优点

  • 最符合任务导向心智
  • 把“先做成事”放在第一位
  • 保留系统能力，但不强迫所有人先学模型

风险

  • 需要定义模板化创建体验
  • 需要明确哪些参数可以托管隐藏
  • 首页如果设计不好，容易变成“漂亮但空”的工作台
