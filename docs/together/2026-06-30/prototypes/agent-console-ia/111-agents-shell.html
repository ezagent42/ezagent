为什么这一页还要存在

熟悉用户仍然需要直达入口

你刚才提的担心是对的：如果所有东西都藏进首页，熟悉系统的人会觉得路径变长。所以 `Agents` 这种对象页必须保留，并且依然能快速筛选、查找、进入详情。

这页和首页的关系

Overview 负责引导，列表页负责管理

新手先从首页开始，老手可以直接进列表。两者不是替代关系，而是协作关系。
