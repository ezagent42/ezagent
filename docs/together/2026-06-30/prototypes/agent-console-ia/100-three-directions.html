Agent Console · 三种方向原型

这页不再只是抽象说明，而是把 3 种产品方向都各自做成一套网页。你可以直接点进去看每种方向下：首页怎么组织、创建入口放哪里、详情页如何承接。建议把这页当成总入口来回切换比较。

A. 对象平铺型

最接近当前控制台思路。对象类型优先，用户先进入 Agent / Session / Keys 等分类，再自己判断下一步动作。

打开 A 方向网页

B. 任务首页 + 对象详情

首页围绕“继续做事”和“开始创建”，详情页承接配置和状态。我当前最推荐这个方向。

打开 B 方向网页

C. 双层模式

把系统拆成“工作台”和“控制台”两种模式。产品感更强，但复杂度也更高。

打开 C 方向网页

怎么看这 3 页
  • 先看每页的第一屏：首页到底先告诉用户什么。
  • 再看创建入口：是先选对象，还是先选用途。
  • 最后看详情页承接：普通用户和高级配置有没有分层。

你可以重点比较的点

  • 首屏是否清楚
  • 创建路径是否顺
  • 现有功能是否有组织逻辑
  • 高级配置是否打扰普通用户

这轮原型先不解决的点

  • 不讨论 kanban 独立产品面
  • 不强行落具体后端 contract
  • 不做像素级视觉精修
