# Agent Console IA Prototype

这套 demo 用来说明本轮 Agent Console UI/UX review 的设计方向，不是实现代码。

## 入口

- `index.html`

## 建议浏览顺序

1. `110-overview-shell.html`
2. `111-identities-directory-shell.html`
3. `112-create-agent-shell.html`
4. `113-agent-detail-shell.html`
5. `123-workspace-detail-shell.html`

## 这套 demo 主要想表达什么

- `Overview` 作为默认 landing page，负责引导第一步
- 左侧栏保留稳定分类导航，不牺牲熟悉用户的直达路径
- `Identities` 在产品层翻译为 `Roster`
- `Capabilities` 在产品层翻译为 `Access`
- `Workspace` 从粗列表页扩展成多层空间视图
