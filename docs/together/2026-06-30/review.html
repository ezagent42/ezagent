§4 流程沉淀

return 必须落文档。 Feishu return 对协作速度很重要，但 close 不能只靠聊天记录。每个 return 要么进 returns/*.md，要么在 stack.md 标注 late/out-of-scope。
大集成分支不能直接合并。 #1110 以后按“证明路径”和“合并单元”分开管理：前者可以大，后者必须小、可 review、可回滚。
UI 原型必须收敛。 prototype 的 DoD 不是截图数量，而是一个路径可用、可验证、能进入产品。
Seed 不能成为产品功能。 业务 persona、语料、routing policy 应进入定义数据/fixture/socialware package；seed 只负责安装、ingest、授权和启动受支持路径。详见 docs/together/contributing/seed-vs-product-boundary.md。
