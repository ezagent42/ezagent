# dealscout 产品文档 1：定位 → 北极星（P 层）

> **一句话**：DealScout 是一个**商业 / 投融资线索的搜索与撮合平台**——名字取自 **deal 侦察兵**（主动侦察、发现投融资 + 商业机会）。核心 = **AI 千人千面发现 deal（找为主）+ 公开面聊天撮合（亮点）**；**两侧都是"找机会的人"**（找钱的 founder、找项目的 investor），不是单向"帮谁找 funder"、也不是"创业者撮合"。两类用户对称，都用同**两条腿**：**发现腿**（地基·AI 千人千面主动发现 + 主动搜索商业/投融资线索）和**撮合腿**（涌现的亮点·**组合 hello 拿公开面 + concierge 客服**，登录用户在公开面自助 join+发言供线索、founder 看到身份后 invite 深聊）。产品取向是 **找为主、撮合为亮点、北极星分期**。
>
> **本文在追溯树里的位置**：这是整套产品↔技术文档的**最上游 P 层**（定位→北极星），是全树的根。**本文编号从"帮找机会的人对接"这个根一路推导下来**——不是几个并列的阶段，而是一条思考链：因为要帮找机会的人对接（P-1），所以要看清楚这件事靠哪几条腿来支撑（P-2 两条价值腿：发现 + 撮合），所以每条腿都得能量出来它有没有兑现（P-3 北极星，分期）。往下走，产品文档 2 的用户旅程（发现腿 + 撮合腿）都 `↑` 挂到本文的 P-3 北极星上；再往下 V（视图）↑J、F（功能）↑V、I（开发 issue）↑F，最终每个开发点都能逐级 `↑` 追回到本文的 **P-1.1 根**。编号权威源与功能底稿见同目录 `../README.md §3`（入口 + 编号骨架）。

## §1 根：帮"找机会的人"对接（P-1.1 · 根，无上游）

这一层回答最根本的问题：**dealscout 为什么要存在？**

### P-1.1 帮"找机会的人"对接：地基是发现副驾（找），撮合是涌现的亮点

投融资和找商机这件事，本质是**一群人在"找机会"，却找得又慢又累**。一边是 founder：想找钱、找路演、找商机，但不知道钱在哪、机会在哪，一个个去搜、去挖、去谈，成本极高。另一边是 investor（VC、投资人、路演机会方、情报源）：想找对的项目、对的标的、对的情报出口，却在茫茫人海里找不到那个"正好对路"的人。**这两拨人其实是同一种人——都是"找机会的人"**，只是一个举着需求、一个举着供给。他们共同的痛，是中间隔着**信息不对称 + 连接成本高**这堵墙。

dealscout 存在的理由，是**先把"找"这件事做到极致，再让"撮"自然长出来**：

- **地基 = 发现副驾（找为主）**：用 AI **千人千面**地帮每个人主动发现、主动搜索机会——按你的 profile 把相关的融资动态、路演信息、商机线索、可投项目捞齐、挖透、备好材料。这是**天天都在用**的地基能力，founder 和 investor 对称地用。
- **亮点 = 撮合（涌现，不当地基）**：当越来越多人把自己"找什么"公开出来，**撮合就作为发现之上的亮点自然涌现**——你**组合 hello 把机会页公开**成一个带 concierge 客服的公开面，别人看到、登录后就能在公开面**自助 join、发言供线索**，你（founder）在同一 session 看到发言者身份、觉得对上了就**主动 invite 他进私有 session 深聊**。撮合很重要、是网络的高光时刻，但它**不是地基**：没有扎实的发现，撮合无从谈起；把撮合当地基（像上一版那样）会本末倒置。

所以 DealScout 从根上是**一张帮找机会的人对接的网**：**先让每个人靠发现副驾把机会找齐（地基），再让撮合作为亮点在上面涌现**。

**边界（收进根，不再是独立节点）**：为了让这个根不飘，得同时划清边界。DealScout **只做到"把机会发现出来、把连接建起来"为止**——只做**发现 + 连接建立**，**不做**交易结算、不做尽职调查、不做资金托管、不替任何一方签任何东西。两边连上头之后，谈不谈、投不投、成不成，是他们自己的事。DealScout 是**帮你找到人、牵上线的那张网，不是签约的那张桌**。边界是根的一条**约束**（框定"做什么、不做什么"），不是一个会往下派生北极星的独立定位——不做的事无需衡量，所以它不单列节点，而是写进根的描述里。（原 P-3.4 边界节点并入此处，见 `../README.md §3.9`。）

## §2 两条价值腿：发现腿 × 撮合腿（P-2.x · 各 ↑ P-1.1）

既然根是"帮找机会的人对接、发现为地基撮合为亮点"，那第一个要拆清楚的就是：**这件事靠哪几条腿支撑？** 答案是两条——一条地基腿（发现）、一条亮点腿（撮合）。**这两条腿两类用户（🔵founder 找钱 / 🟢investor 找项目）都用，对称地走**——所以需求/供给是标在腿上的颜色，不是把腿再劈成两半。

### P-2.1 ↑ P-1.1 发现腿（地基）：AI 千人千面主动发现 + 主动搜索机会

发现腿是 DealScout 的**地基**，也是**天天都在动**的那条腿。它让每个"找机会的人"把自己关心的东西告诉副驾，副驾就替他把机会找齐、挖透、备好：

- **主动发现（push）**：副驾按你的 profile **千人千面**地主动匹配、主动推——不用你每次都去搜，它盯着全网和你指定的源，把跟你相关的融资动态/路演/商机/可投项目**推到你面前**。这是"找为主"里最关键的一环，也是解 yujun"没有发现层"红线的第①条腿。
- **主动搜索（pull）**：你随手一句命令，它就去全网/指定源里**按 query 搜**回来。支持自定义 access token 探查需登录的源。
- **深挖 + 产材料**：对任何一条机会，你能连续追问、多轮深挖，最后让它产出一份能直接用的材料（outreach 材料 / 尽调初稿 / 项目一页纸）。**一切都在对话里完成**，不用学新工具。

两类用户对称：🔵founder 用它找钱的线索，🟢investor 用它找项目的线索——**同一条腿、同一套机制**，只是 profile 和关键词不同。发现腿**今天就能做**（爬取 + 搜索 + recipe 基建都在）。

### P-2.2 ↑ P-1.1 撮合腿（亮点·涌现）：hello 公开面聊天 → founder invite 深聊

撮合腿是 DealScout 的**亮点**——不是地基，是在发现腿之上**涌现**出来的高光。机制是 **hello 公开面聊天**，而**不是** `#1178` 申请加入私有 session（现读代码确认 `#1178` admission gate 是 agent 门、防偷用别人 agent 刷凭证，DealScout 用不上）。它这样跑：

1. **组合 hello 公开机会页**：你 DealScout **组合 hello** 把自己"找什么"（关键词 + 描述 + 发现流）发布成一个带 **concierge 客服 agent** 的公开面。`router.ex:13-14` 结构性保证：非 owner 的访客**永远只跟 concierge 聊、到不了 builder**（改不了你的页），也不为访客发 LLM 调用。
2. **登录用户在公开面自助 join + 发言供线索**：别人（可能是 investor，也可能是另一个 founder——**双向对称**）刷到你的公开面，觉得对路，**登录后就能在公开面自助 join、发消息**（`session_feed_channel.ex:197-228`）——发的消息 @orchestrator → 非 owner 永远路由 **concierge 客服回帖**（`hello_concierge.ex:43`）。**登录用户能聊、能供线索**；**匿名只读不能写**（`session_feed_channel.ex:325-330` + `membership.ex:1200-1208` 两处硬禁）。
3. **founder 本人在场、全量白板互见**：你（founder/owner）也在同一 session 里，**全量白板互见**（`external_feed.ex:85-98`，每个 viewer 看到所有参与者消息），想直接跟真人聊也行。
4. **founder 看身份 → 主动 invite 深聊**：你看到发言者身份（登录=真实 URI 带用户名，`session_feed_channel.ex:353`），觉得某人对上了，就**主动 invite 他进一个私有 session 深聊**（`conversation_actions.ex:683` `invite_member`）——**这是 owner 主动拉，不是申请人申请**。
5. **私密深聊**：进到私有 session 后，双方**按信任选择性披露**、AI 辅助、持续关系通道。聊成了，就是一次**撮合成功**。

**双向对称**是撮合腿的关键：**founder 和访客的角色可以互换**——今天你公开机会页、别人登录进来发言，明天你也可以去别人的公开面登录发言、被对方 invite 深聊。🔵founder 和 🟢investor 在这条腿上是完全对称的两类"找机会的人"。

**为什么撮合是亮点不是地基**：撮合腿完全**站在发现腿之上**——没有发现腿先把"你在找什么"整理清楚、公开出去，别人无从发现、无处发言。撮合是发现结出的果子，很甜、是网络效应的来源（越多人发现 → 越多人到公开面发言 → 越多深聊涌现），但它**长在地基上，不是地基本身**。这也是本版跟上一版最大的区别：上一版把撮合当根，本版把它放回它该在的位置——**涌现的亮点**。撮合腿**今天就能做**（riding hello 公开面聊天：`router.ex:13-14` / `session_feed_channel.ex:197-228` / `conversation_actions.ex:683`），是发现层的第②条腿。

> **发现层第③腿（平台跨用户推荐）在哪？** 三条发现腿里，① 主动找 = 发现腿（P-2.1）、② 公开面聊天 = 撮合腿（P-2.2）今天都能做；**③ 平台跨用户推荐**（关系网层：跨用户实例发现 + 匹配推荐 + 朋友圈图）是**平台方向、缺口、discuss-first**（riding registry track），dealscout 是首个真实需求方但**不阻塞**。它在编号树里作为 F-12/I-14 的 discuss-first 节点，不在 P 层单列。见 `../README.md §4`。

## §3 北极星（P-3.x · 各 ↑ 对应腿，分期）

既然价值靠两条腿——地基的发现、亮点的撮合——那就得能**量出来**：每条腿有没有真的兑现。这一层把 §2 的**两条腿**各翻译成一条北极星。**关键是分期**：地基腿的指标是**近期主指标、天天都在动**；亮点腿的指标是**远期愿景、质量加权**。为什么分期？因为把远期的撮合愿景（双向连接数）拿来当唯一近期指标会误导——撮合是涌现出来的果子，急不得；而发现是地基，天天都该有产出、天天都能量。指标只写"量什么、为什么反映定位、往哪个方向走"，不编具体数字。

### P-3.1 ↑ P-2.1 地基北极星（近期·主指标，天天动）：发现相关机会数 / 搜索满意度

这是**近期的主指标**——地基有没有兑现，天天能量。

- **量什么**：
  1. **发现相关机会数**：副驾主动发现 + 用户主动搜索，一段时间内为每个用户捞回了多少条**相关**（按 profile 匹配）的机会。
  2. **搜索满意度**：主动搜索的结果用户觉得对不对路、有没有用。
  3. **关键词→可用材料的转化率 & 时间**：以关键词/profile 为起点，有多少条机会最终走到"生成一份可用材料"这一步，平均花多久。
- **为什么它反映定位**：P-2.1 说发现腿是天天用的地基。如果机会进不来、搜不准、变不成材料，地基就没立住，撮合也无从谈起。这几个量真实发生，"找为主"才算兑现。
- **目标方向**：相关机会数 ↑、搜索满意度 ↑、转化时间从"以天计的手工搜集"压到**分钟级 / 小时级**。

### P-3.2 ↑ P-2.2 撮合北极星（远期·愿景，质量加权）：公开面真实互动 / 被邀深聊数

这是**远期的愿景指标**——撮合作为涌现亮点，长期看网络到底撮成了多少真连接。**质量加权，不是刷登录发言量**。

- **量什么**：
  1. **撮合成功数（核心，用可观测质量代理，不用 owner 自报）**：撮合成功 = **公开面真实互动 / 被邀深聊**——不是"有人登录发了句话"就算。**区分两个量**：`公开面登录发言数`（漏斗前段、别当质量指标）vs `撮合成功数`（真结果）。撮合成功用**可观测的硬代理**衡量：公开面登录用户与 concierge/founder **持续互动**（多轮以上）/ founder **发出 invite 深聊** / 进私有 session 后**双向确认**（两边都点了"有价值/继续"）/ **下游 email thread 真的动起来**——而**不是** owner 自己点"标记成功"（自报可刷、软）。**质量加权**体现在：只有过了硬代理门槛的连接才计入。
  2. **公开面发言→被邀深聊转化率**（质量信号）：公开面的登录发言里有多少比例被 founder invite 进私有 session 深聊——太低说明信噪差、太高说明门形同虚设，这个比值本身是撮合质量的体温计。
  3. **发现→撮合的涌现率**（网络效应量）：一个用户组合 hello 公开机会页后，平均涌现出多少次有效公开面互动与被邀深聊——反映"越多人发现 → 越多人到公开面发言 → 深聊越密"的正循环有没有起来。
- **为什么它反映定位**：P-2.2 说撮合腿是发现之上涌现的亮点，机制是 hello 公开面聊天 + founder invite 深聊。公开面真实互动/被邀深聊数，直接量的就是这个亮点有没有真的涌现出来。**它挂在撮合腿末端（↑P-2.2）**，但本质上是**发现腿（先把机会公开）× 撮合腿（公开面聊天→invite 深聊）**共同结出的果子——所以它是远期愿景，随发现地基的厚度水涨船高。
- **目标方向**：公开面真实互动/被邀深聊数 ↑（质量加权）；公开面发言→被邀深聊转化率保持在健康区间（既不过滤过度、也不放水）；发现→撮合涌现率 ↑。
