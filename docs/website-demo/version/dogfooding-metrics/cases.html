Case 01 · Dogfooding 自举实证

我们用 Ezagent 构建 Ezagent。

We build Ezagent on Ezagent.

团队将自身的研发与协作流程，全程跑在 ezagent 与 dev-together 编排之上。研发交付吞吐较编排前提升约 1.8× —— 下列数据均取自本仓库真实交付记录，而非市场宣传。

DEMO 本页为 roadmap-v1 样张。标 真实 的指标取自当前仓库 git 与 dev-together 记录（含时间窗与数据源）；标 示例 的为待真实度量的占位。口径见 metrics-spec-draft.md。
Overview · 概览

背景 · 挑战 · 做法

Context · 背景

自己造、自己用

Ezagent 是面向组织的 IDE。开发团队在构建它的同时，把日常研发与协作搬到了 ezagent 自身之上——既是作者，也是第一批用户。

Challenge · 挑战

多人多 agent 的协同

研发涉及多名工程师与多个 AI agent 并行推进，传统方式下计划、交接与交付难以对齐，上下文易丢失、返工成本高。

Approach · 做法

把工作流跑在 Ezagent 上

以 ezagent 的角色 × agent 模型 + dev-together 编排，统一计划、交接、交付与复盘，在生产 workspace 中持续运行。
