## 官网 & hello（→ zhaomato）

### 1. [🟡 P2] 打开 session 按钮：悬浮出现文案「进入 world 查看」
当前按钮无提示，补一个 hover tooltip 说明点击后果。

### 2. [🟡 P2] 打开 session 按钮的小红点更醒目
出现时闪烁两次，提高感知。

### 3. [🟠 P1] 用户提问后，跳转时同时展示 agent 回复文字
现在页面能直接跳转，但 agent 回复的文字内容也有价值——跳转的**同时**把回复文字也展示出来。

### 4. [🟠 P1] 支持页面锚点跳转 + section 标题高亮
用户说「你们有哪些产品」→ 页面跳到首页「一个底座，两个产品」section，且该 section 标题**高亮两次**。当前似乎不支持页面锚点。

## world（→ zyli）

### 5. [🟠 P1] 需要中文版
world 目前无中文。（工作量较大；若 demo 主要停在官网、world 只快速带过，可降 P2。）

### 6. [🟠 P1] 发布按钮更显著 + 明确文案
发布是核心动作（旅程"重建/拥有"一步），当前不够显著，加明确「发布」文案。与 #8 同一处，一起做。

### 7. [🟡 P2] 右侧 member 面板支持收起，默认收起

### 8. [🟠 P1] 去掉工作区右上角失效的「展开 / 刷新」按钮，改放发布按钮
中间工作区右上角的展开、刷新按钮疑似点击无效 → 先移除这两个；把**发布按钮**放到这里，写「发布」。（承接 #6。）

### 9. [🔴 P0] session 选择区「+」创建不稳 / 中文名模板选不到
- **加号有时点击无效**——阻断"建 session"这个核心流程。
- **把 session 保存为模板后，创建 session 时选不到这个模板。** 已定位根因：模板名是**中文**时选不到，改成**英文名**就能找到。
  - **快速修（提示词）:** 创建模板的文本框提示词从「如 官网模板-v1」改为「如 **homesite-v1**」，引导用户用英文名，绕开该 bug。
  - **根治:** 修复"中文名模板不可选"的底层 bug（提示词只是 workaround）。
→ 建 session 是整条旅程的起点，最高优先。

### 10. [🟠 P1] 隐藏 PTY
PTY 目前不支持，先隐藏，避免 demo 里露出不可用功能。
