# 官网优化方向与优先级 v1

> **日期:** 2026-06-30 · **作者:** ruihua (designer) · **状态:** v1（grill 定稿）
> **关联:** plan T4 · PR #1103 · 方向 return `docs/together/2026-06-30/returns/t4-ruihua-website-content.md`
> **方法:** 排序用 **Value/Effort 矩阵**（prioritization-advisor：早期 PMF + 无使用数据 + 小团队 → 不用 RICE）；砍掉项用**阶段闸**绑定上线时机。

---

## 0. 上位约束（grill 已共识，不可漂移）

1. **团队核心目标 = 让 ezagent 自己先能被团队日常用起来（dogfood-usable 产品）。** 官网是**服务主线的次要门面**，不可阻塞主线。
2. **官网准则:真实可信 > demo 花活。** 产品成熟度 = 官网可信度上限；不许用花活制造"很成熟"的错觉。
3. **故事锚点 A:** 让首访者相信「ezagent 真能跑起来、我能上手」。world.cup 真数据=辅证活跃可信；双产品价值=锚点 A 落地后再展开。
4. **无对外造势节点**（demo day/融资/招募暂无明确日期）——故造势类内容不优先。

**推荐执行顺序:** P0-2（低成本先收叙事）→ P0-1（核心证明，zhaomato）→ P1 批量。**P1★ 的度量在 G0 前就该开始埋点/采集**，否则 G0 到了也没数据可展。

## 2. 砍掉 / 降级到 P2（移出上线主站，含上线时机）

> **移出 ≠ 删除**:代码留在 repo，产品 ready 后按"上线时机"复活。沉没成本不是保留理由——判据只有"现在是否服务锚点 A"。

| 降级项 | 为何现在砍 | **上线时机（触发闸）** |
|---|---|---|
| **world.cup 押注 / 同注分彩 / 结算 / 裂变分享卡** | 增长/裂变机制；产品没 ready 前过早，且放大"很成熟"错觉 | **G2 公开放量/拉新阶段** —— 有公开入口 + 真实访问量、需要裂变机制放大流量时。前置:G1 达成 + world.cup 真数据 roadmap(P1-1) 已稳定上线 |
| **driver-license 指挥官驾照测试** | 纯趣味/增长钩子，离"能用"最远 | **G1→G2** —— 当新用户涌入、onboarding/筛选成为真实需求时，作为趣味 onboarding 引导钩子 |
| **achievement-center 个人成就中心** | 登录态 gamified 玩法，无真实数据支撑 | **G3 留存/PMF 深化阶段** —— 有稳定活跃登录用户 + 真实活动数据可填充成就 + 目标从"能用"转向"用得久" |
| **team-office 办公室可视化** | 团队活跃度展示=造势类 | **由对外造势节点触发**（demo day / 招募贡献者 / 融资）即锚点 B 临时升主时；否则常驻 P2 彩蛋 |

## 3. 阶段闸模型（上线时机的参照系）

| 闸 | 定义 | 解锁什么 |
|---|---|---|
| **G0 dogfood-ready**（当前主线） | 团队在生产 workspace 日常用 ezagent（zyli 人肉 full-flow 通过 + dev-team 真实使用） | 官网可信地讲"能用"（P0/P1 全部）+ **解锁 dogfooding 效率成果展示(P1★)**——前提是 G0 前已开始埋点度量 |
| **G1 外部可上手** | 真实外部用户能注册/登录并跑通一个 hello（P0-1 稳定） | onboarding 钩子（驾照测试）开始有意义 |
| **G2 公开放量/拉新** | 进入主动获客（公开入口 + 真实访问量） | 增长/裂变机制（world.cup 押注、裂变卡） |
| **G3 留存/PMF 深化** | 稳定活跃用户，目标转向"用得久/用得多" | gamified 留存（成就中心） |

> 当前在 **G0 之前**。所有 P2 项的最早上线闸都 ≥ G1，**本次框架上线一律不含 P2**。

---

## 4. 一句话总结

本次官网上线 = **P0（真实 hello 试玩 + "能用"叙事）+ P1（真数据进度 / 团队 / 登录 / 品牌一致）**；花活四件套（押注、驾照、成就、办公室）**移出主站、按 G1–G3 阶段闸复活**。**dogfooding 效率成果(P1★)是 G0 后的北极星证据——现在就要开始埋点度量、且只展真实数字。** 官网可信度始终不超过产品成熟度。
