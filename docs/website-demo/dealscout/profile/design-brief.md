# Design Brief: DealScout 个人名片

> **目标**：用户在 DealScout 中建立自己的名片——我是谁、做什么、有什么资源、在找什么。匹配算法需要双向名片才能计算匹配度。
> **PR**：#1378

---

## 1. 流转

```
dealscout/index.html → profile/index.html
  ① 填写身份（姓名/角色/机构）
  ② 填写行业 + 标签（关键词）
  ③ 填写我在找什么 / 我有什么（双向需求）
  ④ 保存名片 → 回到 DealScout 主页
```

## 2. 页面结构

- 身份：姓名 + 机构 + 角色（自由输入 + 常见角色建议）
- 标签：行业关键词 tag 输入（投资/AI/跨境/...）
- 资源与需求：两个文本框——"我有什么资源" + "我在找什么"
- 名片预览：右侧实时预览名片卡片
- 保存 → 回 DealScout 主页

## 3. 不做的事

- ❌ 不实现真实名片存储后端
- ❌ 不验证身份真实性
