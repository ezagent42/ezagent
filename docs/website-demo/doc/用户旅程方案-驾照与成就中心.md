# 用户旅程方案 · 指挥官驾照 + 个人成就中心

> 目标：把 `02-demo-指挥官驾照` 有机融进官网。**不是堆功能，是一条顺的旅程**——
> 测试是钩子、名牌是即时奖励、成就中心是留存枢纽。与官网主张「组织 IDE = 一个人指挥一队 agent」同源。

## 用户旅程

```
官网 index（3 入口，钩子统一「测测你能同时指挥几个 agent？」）
   · 浮动按钮（全局）   · 介绍页 hero 下钩子卡   · world.cup 页入口
   ▼  点击都先进 ——
[A] driver-license.html · 指挥官驾照测试（迁自 02，DS 化）
   5 题（每题埋 ezagent 价值点：「任务静默卡住」=world 消息不丢 / 「人肉中转」=编排）
   → 指挥官驾照名牌（段位 青铜→王者 · 唯一编号 · 百分位 · persona赵钱孙李 · orbit 动画）
   → 收束文案「你刚卡住的地方，正是 world / hello 在解决的」
   → 主 CTA「看我的全部成就 →」
   ▼
[B] achievement-center.html · 个人成就中心（新枢纽）
   ├─ 身份头：你的驾照名牌 + persona（没测过 → "去测一张"占位）
   ├─ 成就墙：已解锁 ✓ + 未解锁 🔒（每个未解锁带"怎么拿"钩子 = 空状态指引）
   └─ 活动区（赚成就，逐个引导）
   ↺ 完成活动 → 回中心解锁（解锁微动画）
```

**常驻入口**：nav 右上「登录」——有名牌后变「我的主页 / 成就」，指向成就中心。

## 设计要点（ezagent-design DS）

- 浅色壳 `#E8E8EB` + 白浮卡 + cobalt 交互；**名牌用暗卡 `#14131C`**，强化"身份证"质感
- 段位色走品牌轴（青铜→红 / 黄 / 蓝 / 翠）；orbit 并发动画保留（几何 SVG，非 emoji）
- 成就墙：已解锁 = 实色卡；未解锁 = 低饱和 + 锁 + "怎么拿"提示（**空状态指引**，ui-ux-pro-max）
- **无 emoji**（锁 / 勾用 SVG）；Noto Serif SC 标题；FadeUpBlur 入场；reduced-motion 降级
- 测试 5 题：题面/段位文案沿用 02（已埋好 ezagent 价值点），只换皮
