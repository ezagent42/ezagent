Overview · 客户简介

客户：Ezagent 开发团队

Ezagent 是面向组织的 IDE —— 一套构建、运行并交付组织 AI agent 的工作台。它的开发团队在打造产品的同时，把自己的日常研发与协作搬到了 ezagent 自身之上：既是作者，也是第一批真实用户。这使「产品是否好用」有了最直接的检验——团队每天都在用它交付。
行业 IndustryAI 基础设施 / 开发者工具
团队 Team7 工程师 + 多 AI agent
场景 Scope研发编排 / 组织协作自举
窗口 Window2026-06-22 → 06-30（8 工作日）
Challenge · 挑战

多人 × 多 agent 的协同难题

研发由多名工程师与多个 AI agent 并行推进，传统方式下三类问题持续消耗效率。

01

计划与交接难对齐

谁在做什么、做到哪一步缺乏统一视图，跨人协作时上下文反复搬运。

02

上下文易丢失

任务在人和 agent 之间流转时，约束、验收标准与历史决策容易遗漏。

03

返工成本高

方向或验收不清导致交付偏差，问题往往到合并前才暴露，返工代价大。

Solution · 解决方案

把工作流跑在 Ezagent 上

以 ezagent 的「角色 × agent」模型与 dev-together 编排，统一计划、交接、交付与复盘。

01
每日编排 · orchestration

dev-together 统一节奏

计划 → 交接 → 交付 → 复盘 形成每日闭环，每个任务有明确归属、验收标准与可追溯记录，多人多 agent 并行而不互相踩踏。

02
可靠流转 · routing

消息与上下文不丢

工作经 ezagent 路由，先落库再处理、有兜底与可恢复；任务流转时上下文随之携带，减少遗漏与重复沟通。

03
组织自举 · dogfooding

不止研发，整组织在用

协作、socialware、看板等组织工作同样路由进 ezagent，团队在真实使用中持续发现并修复产品问题。
