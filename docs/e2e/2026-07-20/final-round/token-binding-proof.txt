# ⑤ person-bound DownloadToken 实证（2026-07-20 final round，#1471 解锁面）

editor(B) 板读渲染出的附件 href token，verify_payload 解出：
  uri:     resource://kanban-e2e/uploads/1c3c154b-63c0-485f-ae36-34b5f73b7a0e-final-spec.txt
  grantee: entity://kanban-e2e/user/editor        ← 绑定读板者本人

浏览器实测（真 cookie 会话）：
  editor 本人 fetch  → HTTP 200，content-disposition: attachment; filename="final-spec.txt"
  owner  重放同 token → HTTP 403（caller != grantee，泄漏 token 无用）

对照：owner(A) 自己渲染出的 token grantee=entity://kanban-e2e/user/owner，A fetch 200。
serve 端按 caller==grantee 判权（取代 message-participation 复查）= kanban-403 根修。
