# 02 发布证据 — 部署级 seed 车道（dealscout rework 终版，2026-07-10）

## 车道（照 kanban 先例）：server 节点内 seed! 拷贝 + scan_dir! 晚扫描发布

辅助脚本（本目录随附 dealscout_publish_e2e.exs，erpc 进运行中的 server 节点
ezagent_runtime@127.0.0.1）依次驱动：

1. `Ezagent.Home.SocialwareSeed.seed!()` —— priv/socialware_seed 的 dealscout
   包幂等拷贝进部署目录 `$EZAGENT_HOME/default/socialware/dealscout/`；
   拷贝后 `diff` 部署侧与本分支
   `apps/ezagent_web/priv/socialware_seed/dealscout/manifest.yaml`
   → **byte-identical**（实测输出 "manifest byte-identical"）。
2. `Ezagent.Socialware.ManifestSeed.scan_dir!("/tmp/dealscout-deploy-only",
   source: "deploy")` —— 只含 dealscout 包的目录（symlink 指向部署目录真实包，
   避开 autoservice 按字母序先扫 fail-loud 的既有无关问题，同 kanban 注记）。

发布走完整 governed import lane：parse → ManifestResolver.resolve →
Conformance.check_candidate → publish_or_upgrade（dev 关 boot scan 为
config prod-only 设计，故在 server 节点显式驱动同一晚扫描车道）。
