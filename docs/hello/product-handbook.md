#### A.3.2 变形金刚 + 递归

**变形金刚**：同一个员工换上不同的 AI 同事组合 → 立刻变成不同岗位。要扩业务，加一组 AI 同事就行 — 不用招新人。

**递归**：AI 同事装上 AI 同事 — 比如老板 AI 同事再装"经销商管理 AI 同事"+"海外市场调研 AI 同事"，相当于又一层组织。

### A.6 设计 / 改造您的会聊的网页

**这是 hello.io 的杀手锏功能**——AI 同事可以**直接改网页**。

#### A.6.1 网页的本质：scene + operations

```
finalScene = replay(initialScene, operations)
```

- **initialScene** = 您的网页起点（由 A.1 上传资料生成）
- **operations** = AI 同事每次对话发起的"改动作"序列

#### A.6.2 11 种元素类型（构成"幕"的最小单元）

| 类型 | 用途 |
|---|---|
| `shape` | 装饰 / 分割 / 背景 |
| `text` | 文字 / 标题 / 段落 |
| `image` | 图片 / 产品图 |
| `video` | 视频片段 |
| `html` | 自定义富文本 |
| `lottie` | 矢量动画 |
| `react` | 复杂交互（表单 / 卡片）|
| `json-render` | 结构化信息面板（含 8 种 section）|
| `act-layer` | 一整幕的容器 + 转场动画 |
| `css` | 自定义动画样式 |
| `js` | 交互逻辑（受限）|

> 📷 截图占位：[元素工具栏——11 种元素 icon 网格]

#### A.6.3 AI 同事的 9 种"改网页"动作

| 动作 | 用途 |
|---|---|
| **ADD_ACT** | 加新一幕（比如客户问售后 → 加售后幕）|
| **UPDATE** | 改某个元素的属性（文字 / 颜色 / 大小 / 动画）|
| **ADD** | 加新元素（一张图 / 一段视频 / 一个对比表）|
| **DELETE** | 删除不相关的元素 |
| **UPDATE_ANIM** | 改动画关键帧 |
| **NAVIGATE** | 跳到对应章节 |
| **ADD_PANEL** | 加面板（侧边信息块）|
| **USE_PRESET** | 用预设视觉块 |
| **USE_TEMPLATE** | 用整套模板 |

> 📹 视频占位：[60 秒——客户提 3 个不同问题，AI 同事分别用 UPDATE / ADD_ACT / NAVIGATE 改网页，客户看到网页一幕幕跟着对话变化]

#### A.6.4 AI 决策树（什么时候改、改什么）

```
   客户提问            AI 同事判断              网页变化
  ──────         ────────             ──────
  
  "Reviews from US?"    文字够答吗？             无（纯聊天）
                            ↓
                        当前幕能增强吗？           UPDATE / ADD
                            ↓
                        需要新一幕吗？             ADD_ACT
                            ↓
                        已有内容能跳吗？           NAVIGATE
                            ↓
                        有现成模板吗？             USE_TEMPLATE
```

### A.7 沙箱演练

**沙箱 = 模拟 channel + customer-simulator AI** — 在不影响真实客户的情况下：
- 测新 AI 同事 / 新装配
- 跨场景 regression 测试

> 📷 截图占位：[沙箱配置页 —— 选模拟场景 / 选要测的 AI 同事 / "开始演练"按钮]

#### 工作流：

1. **配置场景**：选模拟客户类型（如"日本客户咨询" / "投诉处理"）

3. **看结果**：CSAT / 成交率 / 接管次数 / 响应时长
4. **确认上线**：通过验证才推到生产

聊了几句后，客服会发您一个**专属链接** → 打开是一个**会聊的网页**。

### C.3 跨渠道回访 — AI 同事认识您

一周后，您从任何渠道再回来——

AI 同事**直接答**：

# Part 3 · 常见问题 FAQ

## Q1. AI 同事会犯错吗？会乱答客户吗？

**会犯错——但有 3 层保险**：

1. **三模式协作**：Auto / Copilot / Takeover。任何时候可一键切换。
2. **沙箱演练**：新装配先在沙箱跑 100 场景验证再上生产。
3. **自主进化提案**：AI 同事自己发现错误模式 → 提交改进提案给您审。

## Q2. AI 同事生成的物料配不上我品牌？

**物料是半成品**——

- AI 同事生成 TikTok 脚本 / 小红书图文 / 海报草图
- **一键导出 Figma / Canva** → 您的设计师继续打磨
- 消除等待 + 重复劳动，不替代创意

## Q3. 海外私域 / 跨平台延续 / 联通——真的能起来吗？

**我们给工具 + 起步路径，运营投入需要您**。

- 工具：全渠道接入 + AI 同事 24/7 + 会聊的网页 + 跨平台身份联通
- 起步路径：从 TikTok 评论 → 私信 → 网页 → WhatsApp 的具体演示
- 我们承诺：进来的客户**不会因为您不在线**就跑掉

## Q4. 数据安全吗？会被锁住吗？

**不会**。

- 法律协议：您拥有 100% 数据所有权
- 一键导出：45 秒下载全量 ZIP（CSV / JSON / 兼容 ERP）
- 协议明确禁止 OneSyn 转售 / 二次使用
- 多 tenant 4 维隔离

## Q5. 我团队小，学得会吗？

**5 分钟上手**——对话即操作。

- 您的员工会发朋友圈 / 回复客户 / 和同事聊天 → 就会用 hello.io
- 第一周陪跑——OneSyn 客户成功团队全程辅助
- 沙箱里反复练

## Q6. 跨语种支持如何？

**支持主流语种全自动转换**——

- 客户用任何语言进入 → 翻译 AI 同事自动识别 + 实时转换
- AI 同事用客户语言回复
- 您和员工用中文操作即可
- 当前覆盖 20+ 种语言

## Q7. 多 tenant 隔离怎么做？

**4 维严格隔离**：URI / Capability / Dispatch / Data。
适用：多商户聚合平台 / 行业组织 / 跨境集团。

## Q8. 同一个客户跨多渠道，AI 同事真的能记得吗？

**能**——通过 `external_chat_id ↔ user_id 映射` + `session_store` 跨渠道绑定。
第二次进任意渠道，AI 同事加载完整跨渠道历史。

## Q9. 如果我需要的 AI 同事不在默认家族里，怎么办？

**两种方法**：

1. **组合现有同事**：通过 admin 控制台把已有同事按"工作流"串联
2. **自定义新同事**：写 agent template 挂总线

## Q10. "半小时让 AI 网店开门"——开门后是什么样子？

**半小时您会看到**：

- 一个**可跑通**的会聊的网页（含基本物料 / 至少 3 幕）
- **接待 AI 同事**默认装配，能 24/7 接客
- **第一个渠道**接通（飞书 / Web widget 任选）
- **基本业绩看板**

**这是起点不是终点** — 之后您和 AI 同事一起把店越做越厚（详见 Module A.2 - A.10）。
