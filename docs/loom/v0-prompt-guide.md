# 跟 v0 对话:Loom 编辑器提示词大全

> 写给 **Loom 编辑器用户**(在左侧聊天框里 `@编排器` / `@v0` 跟 AI 说话生成页面的人)。
> 这份文档把 v0 **真正会的能力**全部列出来,每条都配了**可以直接照抄的提示词**。
> 你不需要懂代码——你只要会用人话描述你想要什么,v0 就能把它做出来。

---

## 0. 先搞清楚:你在跟谁说话

Loom 编辑器里其实有**一个团队**在帮你干活,你用 `@` 点名谁,谁就接活:

| 你 @ 谁 | 它是谁 | 管什么 |
|---|---|---|
| **`@v0`**(或编排器转给它) | **页面生成器** | 把你的话变成一个真实可点的网页。**这份文档主要讲它。** |
| `@编排器` | 调度 + 内容团队 | 把复杂需求拆开,叫 policy / company 等 worker 写文案,再汇总。需要"先想清楚内容再做页面"时用它。 |
| `@管家` | 团队管理 | 帮你**加 / 删** worker。例:"加一个画家帮我配色"。 |

**最常用的一句话**:直接 `@v0 帮我做一个 XXX 页面`,它就开始生成。
下面所有提示词,默认都是说给 **v0** 听的。

---

## 1. 生成 / 修改页面(最核心)

v0 产出的是一个**真实的 React 网页**(多文件、可交互、带样式),不是截图、不是静态 HTML。

### 1.1 从零生成

> - `做一个卖咖啡豆的落地页,顶部大图 + 下面三款主推商品 + 底部联系方式。`
> - `给我一个个人作品集网站:首页自我介绍,作品九宫格,点进去看大图。`
> - `做一个 SaaS 产品官网,要 hero 区、功能介绍、价格表(三档)、FAQ、页脚。`
> - `仿照苹果官网那种大留白、大字号的风格,做一个手表新品发布页。`

**技巧**:说清楚 ①卖什么 / 是什么 ②要哪几个区块 ③风格调性。说得越具体,一次到位的概率越高。

### 1.2 在现有页面上改

v0 每次都会**看到当前页面的全部代码**,所以你可以连续地、一点点地调:

> - `把主色调从蓝色换成墨绿色 #1a3a2a。`
> - `hero 区的标题再大一点,加一句副标题。`
> - `三个商品卡片改成四个,加上价格和"加入购物车"按钮。`
> - `把价格表那一段删掉,我不需要了。`
> - `整体再高级一点,留白多一些,字体换成衬线体。`

> ⚠️ v0 是**唯一**能改页面源码的角色。发布出去的页面、分享快照、别人 fork 的副本都是**冻结**的,只能在你自己的编辑器里让 v0 改。

### 1.3 多页面 / 页面内切换视图

一个 Loom 页面可以有多个"视图"(像多个 tab / 子页面),v0 能做导航:

> - `做一个商城:首页是商品列表,点商品进商品详情页,顶部有导航栏可以切换"首页/关于/联系我们"。`
> - `加一个商品详情页,点列表里的商品就跳进去,详情页有大图、价格、参数、返回按钮。`
> - `再加一个"为你推荐"页,这个页面不要顶部栏也不要底部栏,只能通过特定入口进。`

## 2. 让页面"活"起来:智能组件(Loom 独有)

这是 Loom 比普通建站工具强的地方。v0 能在页面里埋 **8 种智能组件**,让访客获得 AI 能力、交互能力。你只要描述**想要什么效果**,v0 自己选组件。

### 2.1 ✨ AiSpot——页面里的"AI 热区"

页面任意位置放一个 ✨ 按钮,访客点了,**当场调 AI 生成内容**(讲解、点评、推荐语、扩写……)。

> - `每个商品卡片右上角加一个 ✨,访客点了就用 AI 生成这款商品的卖点介绍。`
> - `在文章末尾加个"✨ 帮我总结全文"的按钮。`
> - `产品参数表旁边放个 ✨,点了让 AI 用大白话解释这些参数对小白意味着什么。`

### 2.2 DataScope——同一份数据,多种视角 + 对比

让访客切换"身份/视角"看同一批数据,还能勾选两项做对比。

> - `做一个企业列表,访客能切换"投资人视角 / 求职者视角 / 客户视角",每种视角强调的字段不一样。`
> - `保险产品对比页:列出五款产品,访客可以勾选任意两款并排对比保额、价格、条款。`

### 2.3 Filterable——筛选 / 搜索

给一堆条目加上按字段筛选、搜索。

> - `商品列表加上按"品类、价格区间、是否有货"筛选,再加个搜索框。`

### 2.4 Spotlight——高亮"爆款 / 推荐"

自动给某些条目加"热门""推荐"的视觉强调。

> - `把销量前三的商品标成"🔥 热卖",视觉上更突出。`

### 2.5 Revealable——折叠 / 展开

FAQ、详情、"阅读更多"这种点击展开的块。

> - `FAQ 部分做成可折叠的,默认收起,点一下展开答案。`

### 2.6 Stepper——数量加减器

带上下限的 +/- 数量选择。

> - `购物车里每个商品加一个数量加减器,最少 1 件最多 10 件。`

### 2.7 askStitch——一键问预览助手

页面里的某个词 / 按钮,点了就把问题抛给右下角的 Stitch 助手。

> - `专业术语都做成可点的,访客点一下就让 Stitch 助手解释这个词。`

### 2.8 组合用

你不用记组件名,直接描述场景,v0 会自动组合:

> - `做一个二手车交易页:车型列表能筛选(价格/年份/里程),每辆车有 ✨ 让 AI 生成"这辆车适合谁",点车进详情页,详情页参数旁有"✨ 帮我砍价话术"。`

## 3. 预览助手 Stitch 的样式(stitchConfig)

每个发布页右下角 / 底部都有一个 **Stitch 对话浮层**(访客和页面对话的入口)。你可以让 v0 调它的外观:

| 能调什么 | 说法示例 |
|---|---|
| **位置** | `Stitch 放到屏幕底部中间,做成一条 bar。` / `Stitch 放右下角浮窗。` |
| **主色 accent** | `Stitch 的主色改成 #272324,跟页面调性一致。` |
| **能不能拖动** | `让 Stitch 浮窗可以拖动。` |

> - `把 Stitch 改成底部居中的一条横栏,主色用墨黑 #272324,跟我这个高级感页面搭。`

> 注:`AiSpot` 卡片的配色也会跟着 Stitch 的 accent 走,所以调一次 accent,整页的 AI 元素调性就统一了。

## 4. 动态数据(重要规则)

v0 生成页面时,**写死的演示数据**(商品、文章、列表)是直接写在代码里的。但有两类数据是**运行时才去取**的,你描述时要意识到:

- **用户上传的东西**、**会话里的对话历史**、**后端实时算出来的推荐** → 这些 v0 会写成"运行时请求",页面打开时现取,而不是写死。
- 所以如果你要的是"**每个访客看到的不一样**"的内容(个性化推荐、上传的文件、实时对话),直接说出来:

> - `首页根据访客的意图实时推荐 3 个商品(不要写死)。`
> - `做一个让访客上传简历、然后 AI 点评的页面。`

## 5. 平台能力(SDK)——让页面接后端

v0 能让页面调用平台提供的能力。你不用懂这些 API,**描述场景**即可:

### 5.1 对话 / 消息

页面能给会话发消息、收消息、读历史(做成聊天界面、留言、客服)。

> - `做一个聊天界面,访客发的消息进会话,AI 回复实时显示出来。`
> - `页面加载时把历史对话都拉出来显示。`

### 5.2 文件上传 + 展示

访客上传文件(简历、合同、图片、PDF),页面能拿到、能显示、能交给 AI 看。

> - `加一个上传区,访客传 PDF 上来,把它发给 AI 帮忙审阅。`(上限 20MB,禁可执行文件)
> - `访客上传的图片,在页面上直接显示出来。`

### 5.3 调外部 API(白名单制)

页面能经平台代理调**已开通的**外部接口。当前开通的:

- **`public` 通道**:`api.github.com`、`httpbin.org`、`jsonplaceholder.typicode.com`(GET / POST)

> - `做个页面输入 GitHub 仓库名,显示它的 star 数和简介。`(走 public 通道打 api.github.com)

> ⚠️ 只能调**已开通**的地址。想接别的外部服务(天气、支付、你自己的 API),需要**运营在后端加 preset**——你在编辑器里说也没用,告诉 Allen / 运营加白名单。

### 5.4 命名工具(tool)

平台预置了一些**稳定的小工具**,比直接调 API 更可靠。当前可用:

- **`now`**:取当前时间(可指定时区)。例:`页面上显示一个实时时钟,用 Asia/Shanghai 时区。`
- **`echo`**:原样回声(烟测用,日常用不到)。

> 想要更多工具(算汇率、查物流、发邮件……)同样是**运营在后端注册**,不是 v0 能凭空变出来的。

## 6. v0 自带的视觉/技术能力(说一声就能用)

v0 默认就能用这些,你想要相应效果直接提:

| 能力 | 说法示例 |
|---|---|
| **图标** | `按钮配上合适的图标。`(用 lucide-react 图标库) |
| **入场 / 滚动动画** | `卡片滚动到视口时淡入上浮。` / `hero 文字做个打字 / 渐入动画。`(framer-motion、gsap) |
| **图表** | `加一个折线图展示近半年销量。` / `用环形图展示市场占比。`(recharts) |
| **精致字体** | `标题用 Playfair Display 这种优雅衬线体,正文用 Inter。`(已内置 Playfair Display / Instrument Serif / Space Grotesk / Inter Tight) |
| **响应式** | `手机上也要好看,商品列表在窄屏变成单列。` |

## 7. 设计质量:怎么让产出更高级

v0 的产出质量很看你给的"调性输入"。几个有效说法:

> - `参考 [某网站 / 某品牌] 的设计语言。`
> - `要那种高端、克制、大留白的感觉,不要花哨。`
> - `配色用低饱和的莫兰迪色系。`
> - `整体更有呼吸感,行距、间距都放大。`
> - `这一版太普通了,重新设计得更有记忆点、更有设计感。`

如果运营配置了**品牌设计规范**(`loom-design.md`),v0 会自动遵循,你不用每次都强调品牌色 / 字体。

## 8. 一次说清的"模板提示词"

把上面的拼起来,一句话就能让 v0 产出相当完整的页面。模板:

> **`帮我做一个【是什么/卖什么】的页面。`**
> **`风格:【调性,如:高级克制 / 活泼年轻 / 科技感】,主色【#色值】。`**
> **`结构:【区块1】【区块2】…【页脚】。`**
> **`交互:【哪里要 ✨ AI 热区】【哪里要筛选 / 对比 / 折叠】【点 X 进 Y 详情页】。`**
> **`Stitch:【放底部 bar / 右下浮窗】,主色跟页面一致。`**

**实例**:

> 帮我做一个高端电动车官网。风格高级克制、大留白,主色墨黑 #272324。
> 结构:全屏 hero(车型大图 + 一句 slogan)、三款车型横向走马灯、参数对比区、页脚。
> 交互:每款车有 ✨ 让 AI 生成"这款车适合谁";点车进详情页(大图 + 参数 + 返回);
> 参数支持勾选两款对比。再加一个隐藏的"为你推荐"页,无顶/底栏,只能从特定入口进。
> Stitch 放底部 bar,主色 #272324。

## 9. 几条避坑提醒

- **v0 改的是你自己编辑器里的页面**;发布 / 分享出去的是**冻结快照**,访客改不了源码(只能在上面叠加自己的操作)。要改内容,回编辑器找 v0。
- **每次让 v0 改东西,它都会重出整页**——这是正常的,它会保留你没让它改的部分。
- **接外部服务 / 加新工具**不是 v0 能力范围,要**运营在后端加白名单**(见 §5.3 / §5.4)。
- **后端改动需要重启服务**(约 4.5 分钟,期间页面打不开);**纯页面调整不用重启**,刷新即可。
- 说不清楚就**先让 v0 出一版**,再基于它一句句调——这是最快的路径,比一开始就憋一段完美需求高效。
