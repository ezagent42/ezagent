# MFU · “孵化中的组织”v0.2 设计

> 日期：2026-07-30
>
> 玩家：孵化器运营者

## 核心体验

孵化器像牧场主，企业和 MVO 是玩家持续培育的组织。首页最值得观看的不是任务列表，而是自己的组织正在工作、休息、遇到问题和逐渐成长。

页面只呈现真实游戏状态，不使用“12 名学生 → 6 个可运行的 MVO”等 pitch 结论文案。

## 首页布局

```text
┌──────────┬──────────────────────────────┬──────────┐
│ 订单板   │        孵化中的组织          │ 待处理   │
│          │  每个组织 + 当前运行内容     │          │
├──────────┴──────────────────────────────┴──────────┤
│                  可展开物品栏                       │
└───────────────────────────────────────────────────┘
```

### 左侧：ToDo List

只展示尚未分配的任务。玩家选择任务后，可以分配给空闲组织，或进入组织图工坊创建新组织。

任务一旦分配，就离开左侧并出现在中央对应组织下方。

### 中央：孵化中的组织

这是首页视觉中心。每个组织地块展示：

- 组织名称、等级与认证；
- 简化组织图和关键成员；
- 当前任务、进度与预计完成时间；
- 空闲、运行、待确认或风险状态。

点击运行中的组织进入执行详情；点击空闲组织进入任务分配。

### 右侧：待处理

展示需要玩家做决定的事项：

- 待验收；
- 待复盘；
- 可升级；
- 风险提醒。

已处理事项进入历史记录，不长期占据首页。

### 底部：物品栏

默认是紧凑的背包栏，只显示人才、Agent、IP / 工具、资金和算力数量。点击后向上展开具体资源卡。

## 状态流

```text
左侧新任务
→ 分配给中央空闲组织
→ 组织运行
→ 右侧产生验收 / 复盘 / 升级 / 风险
→ 玩家处理
→ 组织继续成长
```

## v0.2 实现边界

1. 保留 v0.1 文件，不直接修改。
2. 新建 `mfu-demo/MFU-MVO组织牧场-v0.2-可玩原型.html`。
3. 首页支持选择任务并分配给空闲组织。
4. 支持推进一次运行并在右侧产生待验收事项。
5. 支持验收后增加组织经验并产生可升级事项。
6. 物品栏可以展开和收起。
7. 中央区域分为“办公室 / 孵化中的组织”两个 Tab；办公室代表孵化器自身。
8. 资源栏展开后按人才、Agent、工具、IP / 数据分类；点击 Agent 可以完成一次调教升级。
9. “孵化中的组织”常驻组织图工坊入口。订单可以交给现有 MVO，也可以带着订单进入工坊创建新 MVO。
10. 孵化器 ERP 包含概览、任务、组织、资源、财务和日志六个最小可用页面。
11. 组织详情先展示运行信息和简化组织图；复杂路由编排不迁移。
