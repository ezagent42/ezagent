# MFU 猎人教学关卡 v0.3.2 聚焦修正设计

> 日期：2026-07-29
>
> 状态：设计已在讨论中确认，待 ruihua 审阅本文
>
> 目标原型：`mfu-demo/MFU-协作阵列-v0.1-可玩原型.html`

## 1. 修正目标

恢复 v0.3 原本清楚的关卡流程，只在“编排工作台”和“调教 Agent”两个关键节点增强教学。

v0.3.2 取代 v0.3.1 的连续引导设计。以下 v0.3.1 内容不再进入 demo：

- 独立的卡牌介绍画面；
- 每页顶部“当前目标”；
- 调教、步骤交付和结算的额外提示条；
- 结算页的分工、资源、改进三项评分卡。

保留昵称、订单背景、订单资源、自由编排、错误成果、Form 与守则成本、步骤交付和整单结算。

## 2. 关卡流程

```text
输入昵称
→ 订单背景
→ 编排工作台
→ 首次执行
→ 检查错误成果
→ 调教 Agent
→ Form 确认
→ 重新执行
→ 自己的成果交付
→ 完整订单结算
```

每个页面继续只负责原本的一件事，不增加贯穿全程的目标条或评价系统。

## 3. 编排工作台

### 3.1 用 Tour 认识可编排角色

玩家进入编排工作台后，直接看到完整工作台，不切换到新的介绍页面。

Tour 同时圈出手牌区中的两张卡：

- 玩家本人；
- 玩家的第一个 Agent“小角”。

提示文案：

> 这是你现在可以编排的角色：你自己，以及你的第一个 Agent 小角。

唯一按钮：

> 知道了

Tour 卡片放在手牌区上方或右侧，不得遮挡本人卡牌、小角卡牌或任务位置。

### 3.2 ghost 拖拽示范

玩家点击“知道了”后，出现一次循环的半透明 ghost 动画：

1. ghost 从本人卡牌的真实位置出现；
2. 沿可见轨迹移动到任意一个任务环节；
3. 目标环节同步呼吸高亮；
4. ghost 在目标环节短暂停留后淡出并重新播放。

动画同时显示说明：

> 把角色卡牌拖到任务的某一个环节，决定由谁来完成这部分工作。

这句说明必须与 ghost 同时可见，让玩家同时理解操作方法和拖拽目的。

玩家开始拖拽、点击卡牌或成功安排第一张卡后，ghost 和说明立即消失。系统设置为减少动态效果时，不移动 ghost，只显示卡牌、箭头、目标高亮和同一句说明。

### 3.3 自由编排

- 玩家可以把本人或小角安排到任意任务环节；
- 同一张角色卡可以承担多个环节；
- 教学不规定唯一正确答案；
- 明显不合理的安排可以继续执行，不设置强制拦截。

不同安排在教练提示、首次成果和资源影响中得到自然反馈。

### 3.4 创业教练提示

右侧“阵列预估”改为：

> 创业教练提示

不引入“小柯”等新的具名角色。提示根据当前编排显示一句自然语言：

- 尚未填满：说明还有哪个环节没有安排角色；
- 没有本人检查：提醒 Agent 可能误解需求，但允许继续；
- 全部由本人完成：提醒质量可控，但会占用较多本人时间；
- 本人负责判断与检查、Agent 负责制作：提示这种分工较稳妥。

不显示抽象的分数、等级或“正确答案”。

## 4. 调教 Agent

### 4.1 页面布局

调教页面改为游戏中的卡牌升级界面：

- 小角卡牌位于页面中间靠上的位置；
- 卡牌显示当前算力、已安装工具和已写守则；
- 页面底部横向排列四种升级方式；
- 每种方式的按钮同时显示效果与成本。

### 4.2 四种调教方式

| 方式 | 效果 | 成本 | 本关状态 |
|---|---|---|---|
| 🍱 喂范例 | 二选一鉴别，教出品味 | 半天 | 可查看说明，本关不要求完成 |
| 📏 写守则 | 立下工作规矩 | 半天 | 本关必须完成 |
| 🔍 复盘 | 从打回与落选中学习，收益最大 | 半天 + 复盘素材 | 素材为 0，本关不可完成 |
| 🧰 安装工具 | 获得 Form 等可调用工具 | 现金 | 本关必须购买 Form |

本关中：

1. 玩家先点击“安装工具”，查看并购买 Form；
2. 购买后仍留在同一个调教页面；
3. 玩家再点击“写守则”，在同一页面展开输入区；
4. 保存守则后进入 Form 确认。

“喂范例”点击后只解释用途；“复盘”显示“当前复盘素材 0”，不消耗资源。

### 4.3 成本与成长

- 安装 Form 消耗 ¥80，公司现金从 ¥200 变为 ¥120；
- 写守则消耗半天本人时间；
- 安装工具和写守则只是完成配置；
- 小角在后续重新执行中真实调用 Form 并修正成果后，才形成经过验证的 Agent 成长。

## 5. 页面信息密度

恢复 v0.3 的简洁原则：

- 不在每个页面重复解释整套机制；
- 不在结算新增教学评分系统；
- 不添加新的具名引导角色；
- Tour 只用于第一次认识可编排卡牌；
- ghost 只用于第一次理解拖拽；
- 调教页面只解释四种升级方式及本关要完成的两个动作。

## 6. 状态与恢复

浏览器存档只新增：

- 是否已看过角色卡牌 Tour；
- 是否已完成或跳过 ghost 示范；
- 当前打开的调教方式。

刷新编排页面后不重复已经完成的 Tour 和 ghost。重置教学后重新出现。

## 7. 验收标准

1. 玩家进入编排页时直接看到完整工作台；
2. Tour 同时圈出本人和小角，不遮挡卡牌与任务位置；
3. 玩家知道小角是自己的第一个 Agent；
4. ghost 从真实卡牌区域移动到真实任务环节；
5. ghost 出现时同步说明“安排角色到任务环节”的目的；
6. 玩家操作后 ghost 立即消失；
7. 玩家可以自由安排卡牌，不存在唯一强制答案；
8. 右侧显示自然语言的“创业教练提示”，不显示抽象评分；
9. 调教页中央展示小角卡牌，底部展示四种升级方式；
10. 每种调教方式都明确显示效果和成本；
11. 本关能完成安装 Form 和写守则，并能理解另外两种方式；
12. 页面流程恢复为 v0.3 的九个清晰环节；
13. 刷新后不重复已完成的教学提示。
