# MFU · MVO 组织图编辑器设计

> 日期：2026-07-30
>
> 已确认方案：B，自由画布

## 目标

在“MVO 组织孵化总览”中增加一个可选下钻功能，让孵化器运营者亲手设计一个组织，而不是只能接受平台推荐。

玩家在自由画布中：

1. 新增、移动和删除任务步骤；
2. 连接步骤，表达协作关系和任务流；
3. 点击步骤，为其命名并装入人才、Agent 或 IP / 工具；
4. 消耗算力验证组织图；
5. 验证通过后保存，成为首页中的一个待机 MVO。

## 交互边界

这不是专业流程图软件。首版只支持单向连线，不支持缩放、分组、多人协同、撤销历史或复杂端口设置。

画布默认提供“接收任务”和“交付结果”两个节点，避免空白画布带来的学习成本。玩家可以在两者之间新增步骤、自由移动并连接。

连接操作采用“先点起点，再点终点”。当前待连接的起点需要明显高亮，并提供一句短提示。移动节点采用拖拽。

点击节点后，在画布右侧显示：

- 步骤名称；
- 当前装入的资源；
- 可选人才；
- 可选 Agent；
- 可选 IP / 工具；
- 删除步骤。

## 验证规则

首版只检查四项：

1. 至少存在三个步骤；
2. 从“接收任务”到“交付结果”存在完整路径；
3. 玩家添加的每个实际任务步骤至少装入一名人才或一个 Agent；“接收任务”和“交付结果”只是流程边界，不强制装入资源；
4. 当前算力足够支付 12 点验证成本。

验证结果同时展示预计时间、成本、质量、主要风险和一条 AI 优化建议。验证失败同样扣除 12 点算力。

验证通过后，“保存为 MVO”按钮解锁。保存会将当前节点位置、连线和资源写入 LocalStorage，并在“已经产出的组织”中生成新的待机组织卡片。

## 现有组织图升级

现有六个 MVO 不再全部使用三步直线：

- 校园增长：一个步骤分叉为两条并行路径，再汇合验证；
- 用户研究：两个信息来源汇合后形成结论；
- 社群运营：以运营中枢连接内容、用户、活动和复盘；
- 数据实验：用回路表达持续实验；
- 短视频交付、品牌设计：保留直线结构，作为易读对照。

缩略图和详情页读取同一份节点与连线数据，保证宏观展示与可编辑组织图使用同一套概念。
