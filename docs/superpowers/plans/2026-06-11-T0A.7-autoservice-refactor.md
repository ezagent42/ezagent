# Autoservice Refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development.

**Goal:** Refactor autoservice plugin from hardcoded cinnox → content plugin API, parameterized by tid. Add master_admin role.

**Architecture:** Modify existing `customer_session.ex` to use content plugin (TenantContent, SoulRenderer, KbMcpProvider). Add `master_admin` to `roles.ex`. Mark `cinnox_assets.ex` and `cinnox_runtime.ex` as `@deprecated`.

---
### Task 1: Refactor customer_session.ex

Replace hardcoded cinnox calls with content plugin API:
- `CinnoxAssets.build_fast_ack_prompt()` → `File.read!(TenantRuntime.path(tid, :release, ["config","fast_ack_prompt.md"]))`
- `CinnoxAssets.default_soul_slot_values()` → `SoulStore.defaults(tid, role)`
- `CinnoxRuntime.materialize_cinnox_cc!()` → `TenantRuntime.materialize(tid, role, :release)`
- `@deepseek_api_url` / `@deepseek_model` → read from `agents.yaml`

Update `provision/2` to accept `:tid` parameter. All `cinnox` strings → `tid`.

### Task 2: Add master_admin role

In `roles.ex`, add `bundle(:master_admin, _workspace_uri)` with workspace:any + content:any caps.

### Task 3: Mark deprecated

`cinnox_assets.ex`: add `@deprecated "Use EzagentPluginContent.Soul.SoulRenderer"`  
`cinnox_runtime.ex`: add `@deprecated "Use EzagentPluginContent.Tenant.TenantRuntime"`

### Task 4: Verify

Run `mix test apps/ezagent_plugin_autoservice/` and `mix compile` — should succeed.

**Plan complete.**
