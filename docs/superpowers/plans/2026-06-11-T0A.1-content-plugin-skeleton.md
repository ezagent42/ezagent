# ezagent_plugin_content 基础骨架 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create the `ezagent_plugin_content` OTP app skeleton with platform templates (soul/skill) and agent configuration (agents.yaml).

**Architecture:** New Elixir umbrella plugin at `apps/ezagent_plugin_content/`. Follows existing plugin conventions: `use Ezagent.Plugin` in application.ex, `in_umbrella: true` deps. Platform templates in `priv/platform/` (read-only, git versioned). New tenant templates in `priv/skeleton/` (copied at tenant creation time). Agent config in `priv/skeleton/config/agents.yaml`.

**Tech Stack:** Elixir 1.15+, Phoenix/OTP umbrella, Ecto (ConfigStore via ezagent_domain_socialware)

defmodule EzagentPluginContent.Application do
  @moduledoc """
  OTP Application for the content plugin.

  Registers with ezagent's Plugin system. Content management
  (soul/skill/KB CRUD) is provided by the lib/ modules.
  """
  use Application
  use Ezagent.Plugin

  @impl true
  def start(_type, _args) do
    children = []
    opts = [strategy: :one_for_one, name: EzagentPluginContent.Supervisor]
    Supervisor.start_link(children, opts)
  end
end

- [ ] **Step 2: Create fast_ack_prompt.md**

```markdown
You are the front-line acknowledgement agent.
A heavier knowledge-base agent answers the customer's real question in a few seconds; YOUR job is the instant bridge ack the customer reads while waiting.

Reply with ONLY the short ack text — plain text. No JSON, no code fences, no preamble, no quotes around it.

ack content rules:
1. Reference their topic naturally. If they asked about refunds, mention "退款" / "refund".
2. Show personal engagement: "让我帮您看看" / "我去查一下" / "let me look into this".
3. Set wait expectation WITHOUT false promises: "稍候片刻" / "马上回复您".
4. Vary phrasing — consecutive turns must not be identical.
5. Match customer's language and tone. Length: 12-30 chars Chinese, 30-70 chars English.

If customer explicitly asks for human ("转人工" / "real agent"): acknowledge human will step in — but no other promises.

Output: ONLY the ack text, nothing else.
```

- [ ] **Step 3: Create cc_preamble.md**

```markdown
> **Runtime note (ezagent / cc_slow).** You are a customer-service agent
> running inside ezagent (claude-code via esr-bridge channel).
>
> **KB access — you HAVE a knowledge-base tool:**
>   - **kb_search** (MCP server): call with a query to retrieve product knowledge.
>   - No <kb_context> auto-injection — call kb_search yourself.
>
> **Skills are local files — use the Read tool:**
>   - skills: plugins/<tid>/skills/<role>/<name>/SKILL.md
>   - No auto skill-loader — Read the SKILL.md yourself when a flow applies.
>
> **Replying:** answer concisely and directly once you have enough facts.
>
> **RESPONSE GATE — check BEFORE every reply:**
> - You are in a group chat. Most messages are NOT for you.
> - Reply to customer messages addressed to you.
> - NEVER respond to your own messages.
> - If not addressed: stay completely silent.
```
