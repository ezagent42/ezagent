# hire（找 hire）价值链 —— 入口文档 + 权威编号源

> **一句话**：hire = **一个 OPC 对树洞说出自己缺的岗位 → 平台把那份能力招进他的 session 并留下 → 他和这份能力长成一个能被别人拼进去的组织**。核心价值 = **「说出你缺什么岗位 → 把那份能力纳入你可应用的范围」**，不是又给你一个要伺候的 agent。对应官网**旅程 1（找 hire · 树洞版）**，与 DealScout（找 investor · 撮合版，旅程 2）并列、共享官网门面。产品取向：**补能力为地基、成为可组合单元为亮点、北极星分期**。
>
> **Date**: 2026-07-06 · **作者**: Claude（与 ruihua）· **性质**: PM/designer 的产品思路梳理（**不落地实现**；研发已有方案）。深度到 **feature 层**，`已落地/愿景` 标注沿用旅程 1 文档的边界判断、**具体 file:line 由研发核实**。
>
> **文档地图**：本文 = 入口 + 编号骨架 · `model.md` = 支撑概念模型（纳入 vs 组合 / 成员持久化 / public_view / anon→login） · `product/1` = P 定位→北极星 · `product/2` = J 旅程（引旅程 1 全文） · `product/3` = V 视图 · `product/4` = F 功能（标 已落地/愿景）。

## 1. 编号规则

- **前缀**：`P` = 定位→北极星 · `J` = 用户旅程 · `V` = 视图与操作 · `F` = 功能点。（对齐 ezagent kanban plugin 的 stage 序 `positioning→metric→pain→anchor→ux→feature→issue`：P 覆盖 positioning+metric+pain+anchor，V=ux，F=feature；issue 层本轮不下钻。）
- **格式**：`前缀-层.序`（例 `P-1.1`）。
- **唯一上游 `↑`**：每节点恰一个父，只指上一层（J↑P-3、V↑J、F↑V）。构成一棵从「补能力/成为单元」根到功能点的推导树。
- **两条价值腿是颜色，不是分层**：🟦 补能力腿（地基）/ 🟨 成为可组合单元腿（亮点）标在节点上，说明该节点属于哪条腿；父子结构仍是严格单亲树。

## 2. 编号骨架（traceability index）—— 权威编号源

### 2.1 P · 定位 → 北极星（`product/1`）

**层 1 · 根（无上游）**
- **P-1.1** 帮 OPC「说出缺什么岗位 → 把那份能力**纳入**自己可应用的范围」。**边界**（收进根）：只做**发现 + 把一个 hire 招进你的 session 并留下**；**不做**雇佣关系 / 薪酬 / HR / 绩效——hire 是「接管一个岗位并留下的成员」，不是一份劳动合同。

**层 2 · 两条价值腿（↑ P-1.1）**
- **P-2.1** ↑P-1.1 🟦 **补能力腿（地基）**：对树洞说出卡点 → 编排器把一个 hire（agent / user / org）招进**同一** session 并留下 → 能力进你的摊子。**今天就能做**（`add_managed_member`）。
- **P-2.2** ↑P-1.1 🟨 **成为可组合单元腿（亮点·涌现）**：你和 hire 的 session 形态存成一个可对外的**组织 A** → 别人卡点时把组织 A 当 hire 接进去。**部分愿景**（组织作为可被接入的单元）。

**层 3 · 北极星（分期，↑ 对应腿）**
- **P-3.1** ↑P-2.1 🟦 **补能力北极星（近期·主指标，天天动）**：招进并**留下**的 hire 数 / 卡点→能力补齐的转化率 & 时间。
- **P-3.2** ↑P-2.2 🟨 **成为单元北极星（远期·愿景，质量加权）**：成为组织 A 数 / 组织 A 被别人**接入深用**数（不是"存了个模板"就算，要真被别人当 hire 拼进去）+ **供给侧 expertise 租金捕获**（交易模型闭合项，`model.md` §6）。

> **⚠ 核心命题 + 第一证伪点（`model.md` §0/§6，2026-07-06 yujun 核算后加）**：本价值链的新体验不是"AI 替你做"，是"**专家经验(承载在 hire 里)替你做，你把它纳入自己的组**"；供给侧靠"**一份专家经验 agent 化后一份成多份**"(机会成本近零) + expertise 租金转起来。**整条链的承重假设 = hire 必须真承载专家经验、不是通用 agent 换皮** —— 这是该最小代价优先验证的第一假设，也是平台质量门的 core job（守不住则飞轮反向瓦解）。

## 3. 追溯自检

- **节点数**：P 5 · J 6 · V 5 · F 8。
- **严格单亲树**：每节点恰一个 `↑`、只指上一层、非叶节点必有子。两条腿是颜色属性、不参与父子结构。
- 每个 F 逐级 ↑ 回到 **P-1.1（补能力/成为单元根）**，无断链。例：`F-2（招 hire）↑ V-3（回话流）↑ J-3（有人接住）↑ P-3.1 ↑ P-2.1 ↑ P-1.1`。
- **动词纯度**：补能力腿全程 **纳入**（F-1..F-4），成为单元腿全程 **让自己成为可被纳入的单元**（F-5..F-8）——没有一处是 DealScout 式「连接两个仍独立的 party」。这是 hire 价值链区别于 DealScout 撮合价值链的承重点。
