# hire 产品文档 3：视图与操作（V 层）

> **一句话**：把 J 层每一步旅程翻译成官网上一块**看得见、点得动**的界面。V-x ↑ 对应 J。视图形态沿用旅程 1 的树洞门面；本文只列"哪块界面承载哪步价值"，不画像素稿。
>
> **上游**：V-x ↑ J-x（`2-旅程.md`）。**下游**：F-x ↑ V-x（`4-功能.md`）。

---

## 🟦 补能力腿视图

### V-1 ↑ J-2 树洞 bar / composer

官网底部那条树洞输入条 —— 用户对绑定 session 说话的地方。匿名、零登录。

```
┌─ 官网 树洞 bar ──────────────────────────────────────────────────┐
│  🕳  [ 对着树洞说点什么…你搞不定的那件事 ]   [ 说 ]   [有人接住了 ●] │
│         匿名 · 不用登录                        发送      (红点计数)   │
└──────────────────────────────────────────────────────────────────┘
```

- **说话**：`AnonUser` 匿名输入卡点、点「说」→ 话落进绑定 session。
- **入口摩擦最小化**：不登录、不建项目，说一句话即可 —— 承载 J-2"承认我缺的成本降到零"。

### V-2 ↑ J-4 成员看板（hire 进来了、没走）

一块能让用户"回神"的地方：打开看到那个 hire 还在 session 里、是持久成员。

- 展示：当前 session 的成员列表（你 + 招进来的 hire），每个 hire 标 `role_name`（营销 / 法务…）。
- 关键体验：**"没走"** —— 不是聊天记录里一条回复，是一个留在你摊子里的成员。承载 J-4"我不再是一个人 / 能力进了摊子"。

### V-3 ↑ J-3 hire 回话流 + 红点血脉

用户不离开官网也能知道"我那句有人接住了"的地方。

- **红点**：session 每多一条来自 hire 的消息，「有人接住了 ●」+1；打开清零。
- **回话流**：展开是 hire 就着你的卡点接话的对话。承载 J-3"涌现①：有人接住"—— slogan 在这里被演出来（回你的是 hire 不是 agent）。

## 🟨 成为可组合单元腿视图

### V-4 ↑ J-5 认领面（起名 / 认领 owner）

用户想把 hire 留住、给"你俩"起个名时的界面 —— 高潮的落点。

- 操作：给当前 session 形态起个组织名 → 触发 `save_template_as`；顺势 `anon→login takeover` 认领 owner。
- 体验：**双重身份跃迁**（个人→组织 A、匿名→被认领的你）在一个手势里完成。承载 J-5"我们成了一个组"。

### V-5 ↑ J-6 对外机会页（组织 A 的 public_view 脸）

组织 A 对外的那张脸 —— 也是别人卡点时能"接住"它的入口。

- 展示：组织 A 的能力概览 + 一个"把它接进我的 session"的 CTA（**愿景层**：组织作为可被 `add_managed_member` 接入的单元，依赖 #1120）。
- 体验：环闭合 —— 对树洞吐槽的你，成了别人树洞里接住对方的 hire。承载 J-6"别人循着你的洞来接你"。**用暗示 + CTA 收，不做实操演示。**
