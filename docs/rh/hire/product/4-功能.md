## 🟦 补能力腿功能

### F-1 ↑ V-1 树洞 composer：`public_view` + `AnonUser` 匿名写入口 **[已落地]**

- **做什么**：官网底部树洞输入条，允许匿名访客零登录写入绑定 session。
- **原语**：`public_view: true`（整条匿名访问生命周期的结构性授权开关，fail-closed）+ `AnonUser`（首访即铸匿名身份）。
- **现状**：已落地（socialware `public_view` + #68 anon-user）。

### F-2 ↑ V-3 编排器听卡点 → `add_managed_member` 招 hire **[已落地]**

- **做什么**：session 编排器读到用户卡点 → 从 AgentTemplate 招一个对口 hire 进**同一** session、成为带稳定 `role_name` 的成员 + 回话。
- **原语**：`add_managed_member`（orchestrator MCP 工具，"招人进组"）。**hire 的技术锚。**
- **现状**：已落地（orchestrator 工具）。
- **⚠ 第一证伪点（`model.md` §0/§6）**：`add_managed_member` 招进来的 hire **必须真承载专家经验**（专家 authored 的 AgentManifest / 真专家 human / 真专家 org），**不是套了"营销"系统提示的通用 agent**。这是整条价值链的承重假设、平台质量门（底线需求）的 core job —— **本功能的验收不能只验"招进来了"，要验"招进来的是专家 steer 的能力"**。
- **待议（承旅程 1）**：hire 怎么被恰好召来 —— 现写"编排器听卡点自动招人（命中感）"；备选"洞里冒几个候选 hire 让用户挑（选择感）"。

### F-3 ↑ V-2 session 成员持久化（hire 留下） **[已落地]**

- **做什么**：招进来的 hire 是持久成员，不是一次性回复；用户下次回来它还在。
- **原语**：session 成员身份 + 成员生命周期（持久，非临时）。
- **现状**：已落地。这是"hire ≠ 又一个 agent"的落点 —— 留下才叫 hire。

### F-4 ↑ V-3 hire 回话 + 红点血脉 **[已落地]**

- **做什么**：hire 就着卡点接话；每条新消息让「有人接住了 ●」红点 +1，用户不离开官网也感知到"有人接住"。
- **原语**：session 消息 + 红点计数（同构官网旅程 36–39 的红点机制）。
- **现状**：已落地。

## 🟨 成为可组合单元腿功能

### F-5 ↑ V-4 `save_template_as`：存成可版本化 / 可 fork 的 SessionTemplate **[已落地]**

- **做什么**：把当前 session 形态（你 + hire 的协作结构）快照成一个全新的 SessionTemplate 家族，可版本化、可 fork。
- **原语**：`save_template_as`（orchestrator 工具）。
- **现状**：已落地。这是"成为组织 A"的技术锚。

### F-6 ↑ V-5 `public_view` 对外面（组织 A 的脸） **[已落地]**

- **做什么**：组织 A 带一个 `public_view` 对外面，别人不登录也能看到它是"能被接住的能力"。
- **原语**：`public_view: true`（复用 F-1 同一开关，此处装在组织 A 的模板上）。
- **现状**：已落地。

### F-7 ↑ V-4 `anon→login takeover` 认领 owner **[已落地]**

- **做什么**：用户在"成为组织 A"那刻登录，匿名足迹被物理改名为确认用户 —— 身份恰在价值兑现处结晶。
- **原语**：`anon→login takeover`（#68 anon-user epic）。
- **现状**：已落地。

### F-8 ↑ V-5 组织作为可被 `add_managed_member` 接入的单元（嵌套） **[愿景]**

- **做什么**：别人卡点时，把**整个组织 A** 当作一个 hire `add_managed_member` 接进自己的 session（组织接组织 = 嵌套）。这让 J-6 的环真正闭合。
- **原语**：`add_managed_member` 今天招的是**一个 agent**，不是**一整个组织**；"组织作为可组合单元"依赖 **app package 容器**（`grep AppPackage apps/` 目前为空，正收口 #1120 / T7）。
- **现状**：**愿景**。旅程 J-6 用"暗示 + CTA"收、不做实操演示，正好避开这个尚未落地的坑。**这是本价值链唯一的愿景项，也是研发下一步最该盯的收口点。**
