## §0 上游:官网多旅程门面架构(树洞一门面 · solutions 装 N 旅程)

> 这一节是**两条旅程共同的上游**,解释为什么它们同处一个官网、却各写一条旅程。J1、J2 都 `↑` 挂在这里。

**为什么拆旅程(俞军世界观第 3 条)**:用户不是自然人,是**需求的集合**。同一个 vibe coder,在「我一个人干不完营销」情境下,和在「我做出来了但找不到对的钱」情境下,是**两个不同的用户**。两个用户 → 两种痛点 → 两个 hook、两套表述。**合成一条会让 slogan 塌(hire=纳入 与 撮合=连接 是两个动词);拆成两条,各自动词纯,分开就不互撞。**

**为什么同处一个官网(共享媒介)**:两条旅程复用**同一层媒介** —— **树洞(hello 支持的 public_view 对话式公开面)** + **同一个门面手势(说出你在找什么)**。这是真同构,不是硬凑:DealScout 撮合腿与 hire 旅程都骑「组合 hello 拿公开面 + concierge」这层底座。

**但兑现不同(所以必须拆)**:

| | 旅程 1 找 hire | 旅程 2 找投资/项目 |
|---|---|---|
| 门面手势 | 说出你**缺什么岗位** | 说出你**在找什么钱/项目/人** |
| 核心动词 | **纳入**(能力进你的组,成一个组) | **连接**(牵两个仍独立的 party 上线) |
| 兑现原语 | `add_managed_member`(招 worker 进组) | 发现腿(千人千面爬取/搜索)+ `invite_member`(牵对等方进私聊) |
| slogan | You need a **hire**. | Let the right one **answer**. |

```
┌─ 官网门面 · 树洞 ────────────────────────────────────┐
│   「说出你在找什么。」                                  │
│   solutions ▾                                          │
│     · 补岗位 / 找 hire   → 旅程 1(纳入)               │
│     · 找钱 · 找项目 / 撮合 → 旅程 2(连接) ← 本文       │
│     · (未来)情报 / 发现  → 纯发现腿                    │
└────────────────────────────────────────────────────────┘
```

> **统一承诺(master hook)**:**说出你在找什么,让对的那一方应声。** 每条 solution 把它特化成自己的 hook。**叙事连续性彩蛋**:一个 OPC 在旅程 1 长出「组织 A」后,正好可能进旅程 2 去找钱 —— 但它们仍是两条独立旅程,只是同一个人的两个情境。

## Slogan(旅程 2)

> **To OPCs and OPC-to-be: You don't need a bigger pipeline. You need the right one to answer.**

- `pipeline` = 又海投一轮 BP / 又加一批陌生人脉(对独狼 OPC 是**更多**无效功)。
- `answer` = 对的那一方,**循着你说出的信号**露面、接上你。
- slogan 的技术锚:**answer = 发现腿把对的人/机会捞到你面前 + `invite_member` 牵成一条私聊边**,不是又一次冷启动海投。

## 目标用户

同官网定位的 **vibe coders / OPC**,但此刻处在**另一个情境**:东西做出来了(可能刚在旅程 1 长成组织 A),缺的不再是岗位能力,而是**对的钱 / 对的项目 / 对的联合创始人**。痛点从「我一个人干不完」变成「我在大海里捞对的那一方,捞得又慢又冷」。镜像用户 = investor / 机会方(找项目、找标的)—— 两类都是「找机会的人」,对称地走同一条旅程,只是**对树洞说的话不同**。

> **这条旅程的杀手锏不是「帮你多认识几个投资人」,而是:你不用海投、不用求人 —— 说出你在找什么,AI 循着它把对的那一方找齐、露面,你挑对上的牵成一条真连接。你自己那句「在找什么」,也成了别人在找时能应声的信号。**

## 这是什么

一个找机会的人走一条连续旅程:落地官网(撮合 solution)、**匿名对树洞说出「我在找什么」**,发现 AI 循着这句话把对的机会/人捞到面前、其中真有对的一方露了面,回过神时 —— 他和那一方已经牵成了一条能继续谈的私聊边。全程门面在树洞,深聊进私有 session 是自然升级。

## 一句话锚点

> 你以为你又要开始新一轮 BP 海投 —— 结果你只是对树洞说了句「我在找种子轮的钱」,对的那一方就循着这句话应声了。**你没多投一百次,你多了一次对的相遇。**

## 官网 树洞 bar —— 说出你在找什么,回神时对的一方应声了

```
┌─ 官网 树洞 bar(撮合 solution)────────────────────────────────────┐
│  🕳  [ 说出你在找什么…种子轮的钱 / 对的项目 / 联合创始人 ] [ 说 ] [有人应声 ●] │
│         匿名 · 不用登录                              发送        (红点计数) │
└────────────────────────────────────────────────────────────────────────────┘
```

- **说话**:匿名(`AnonUser`,零登录)对树洞说出「你在找什么」,点「说」——话落进页面绑定的 world session,触发发现腿。
- **红点 = 有人应声**:AI 发现的匹配机会/人、或循着你信号登录进来发言的真人,每来一条「有人应声 ●」+1。
- **深聊升级**:想跟某个露面的真人接上,才登录 → 亮出你的机会页 → invite 进私聊。

## 旅程(6 段)

| 段 | 访客动作 | 底层产品关系(ezagent / DealScout 原语) | 价值时刻 |
| --- | --- | --- | --- |
| **0 树洞门脸 == 会应声的公开面** | 打开官网撮合 solution,看到树洞开口「说出你在找什么」+ 树洞 bar;匿名 | 页面 = 绑定 world session 的 hello 产物 + 组合 hello 拿公开面 + concierge(DealScout J-6/F-8);`public_view` 允许匿名进(`AnonUser`) | 不是又一个 FA 中介 / BP 投递箱,是一个「说了在找什么、对的一方可能应声」的开口(复用 J1 同底座) |
| **1 对树洞说出「我在找什么」** | 匿名说「我在找种子轮的钱,做 AI infra 早期」(founder)/ 镜像「我这支基金找 AI infra 种子项目」(investor) | 发言落入绑定 session;编排器听到 → 发现腿启动(**没指定源 → 先爬公开网页**,DealScout 支持);仍 `AnonUser` | **说出「我在找」的成本降到零** —— 你只是说了句在找什么,没海投、没求人、没建 CRM |
| **2 有人 / 机会应声(涌现①)** | 不用配一堆源,AI 副驾把匹配你「在找」的机会/人捞到面前,每条标「为什么对上你」 | 发现腿 J-2 千人千面主动发现(F-2)+ 标注来源;concierge 先接住来意 | **slogan 被演出来**:回你的不是「再投一次的表单」,是 AI 循着你说的在找,把对的那类人/机会**找齐、排好** |
| **3 回神:对的人露面了** | 想接上其中某个真人 → 登录,把你的「在找」亮成一个公开机会页;有人循着它登录进来发言供线索;你全量白板看到 TA 真实身份 | `anon→login takeover`;组合 hello 公开机会页(J-6)+ 登录自助 join+发言(J-7/F-9)+ founder 全量白板看身份(J-8/F-10) | ★你在找的那类人,**真的循着你的信号露了面** —— 是带真实身份的人,不是一条冷线索 |
| **4 回神:牵成了一条线(★高潮)** | 你判断某人对上了 → invite TA 进私有 session 深聊;按信任选择性披露;聊出眉目 = 撮成一条边 | founder `invite_member` 进私有 session(J-9/F-11)+ 选择性披露 + 撮合记账(喂 P-3.2 撮合北极星) | **★不是「纳入你的组」(那是旅程 1),是牵成一条真连接** —— 从孤身大海捞针,到跟对的一方连上了线;身份此刻从匿名认领成你 |
| **5 别人循着你的洞找你(结尾弦 / CTA)** | 你的机会页现在也是「别人在找时能应声的一方」;founder↔investor 对称,你既在找、也能被找 | 你的 `public_view` 机会页 == 别人段 2 里被 AI 发现 / 被牵来的那一方;平台跨用户推荐(第③腿 F-12,**缺口/discuss-first,愿景层**) | **环闭合**:对树洞说「我在找钱」的你,成了别人「找项目」时循着信号应声的一方 |

> **动词纯度守护**:本旅程从头到尾是 **撮合 = 连接**(牵两个仍独立的 party),**没有一处纳入**。所以它有自己的 slogan(answer),不借旅程 1 的 hire —— 两条旅程共享树洞媒介,但价值时刻各自独立,这正是「拆旅程」要保住的东西。

## 胜负手:为什么是「应声」不是「海投」

```
┌─ 海投(别家投融资平台)──────┐   ┌─ 应声(这条表述)──────────────────────┐
│ founder → 群发 100 份 BP      │   │ 你对树洞说「在找什么」→ AI 循信号捞对的人  │
│ → 等回复 → 大多沉底           │   │ → 对的一方露面 → 你 invite 牵成一条边      │
│ 终点 = 「投出去了」            │   │ → 你的「在找」成了别人找时能应声的信号     │
└───────────────────────────────┘   └──────────────────────────────────────────┘
        广撒网、单向、冷            段5 出口 == 段2 入口,对称闭合(founder↔investor)
```

> 官网若能让访客在**段 4 那一刻**回神「我没有海投,我只是说出在找什么,对的那一方就循着它应声、还牵成了线」,这条表述就立住了。它区别于一切「帮你多认识几个投资人」叙事的承重点:**不是扩大 pipeline,是让对的那一次相遇发生。**

## 已落地 vs 愿景(诚实边界)

- **段 0–3 有真原语撑**:组合 hello 公开面 + concierge(`router.ex`/`hello_concierge.ex`)、发现腿千人千面发现+爬公开网页(DealScout F-1/F-2)、`anon→login takeover`、登录自助 join+发言、founder 全量白板看身份(`session_feed_channel.ex`/`external_feed.ex`)—— 都在 main / DealScout 开工范围内。
- **段 4 部分愿景**:`invite_member` 牵进私有 session 已落地;但「AI 发现的陌生对端**在你 session 里现身**让你直接 invite」这一步,冷启动首跑更接近**你去对方公开面发言 / 对方来你公开面**的双向撮合,纯「AI 发现→一键牵成」偏愿景。**段 4 用「invite 深聊 + 撮合记账」收,不夸张成一键成交。**
- **段 5 是愿景外推**:「平台跨用户把『你在找的』和『别人已发布的』自动撮到一起」= DealScout 发现层**第③腿(F-12/I-14,discuss-first 缺口)**。**段 5 用「暗示 + CTA」收,不做实操演示。**

## 本旅程编码的产品决策

- **与旅程 1 并列、不合并**:共享树洞门面 + solutions 菜单,各写一条旅程、各保 slogan;硬伤(hire 纳入 vs 撮合连接)靠架构消解,不靠合成或降格。
- **门面手势统一「说出你在找什么」**,兑现按 solution 分流(纳入走 `add_managed_member`,连接走发现腿 + `invite_member`)。
- **动词纯度 = 连接**,全程不纳入;高潮落在「牵成一条真连接」,不蹭旅程 1 的「成为组织」。
- **匿名贯穿段 1–2**,身份在段 3「亮出机会页 / 想接上真人」那刻结晶(接 `anon→login takeover`);说出「在找什么」在匿名保护下,身份在要接上真人时才暴露。
- **对称收尾**:founder↔investor 角色可互换,段 5 出口(你成了能被找的一方)== 别人的段 2 入口。

## 附 · 设计决策溯源(2026-07-06)

1. **触发**:#1191 作者提「DealScout 可融入 J1」。Claude 首判「hire=纳入 vs 撮合=连接」硬伤,一度推荐「降格成 J1 段 5 案例」。

4. **修正小前提**:「找 hire 和找 investor 功能相同」不严谨 —— 共享 hello 公开面底座,但 `add_managed_member` / `invite_member` / 发现腿是三个不同核心动作;兑现不同正是「必须拆旅程」的根据。
5. **门面架构定型**:官网 = 树洞一门面 + solutions 装 N 旅程;统一承诺「说出你在找什么,让对的那一方应声」,各 solution 特化 hook。
6. **本文 = 旅程 2**:投融资撮合,动词 = 连接,slogan = answer,6 段镜像 J1 格式、绑 DealScout 真原语、标 已落地 vs 愿景。
