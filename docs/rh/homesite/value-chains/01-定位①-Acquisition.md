# 定位① · Acquisition（→ 浏览量）· 树状

> **官网 = 一个 loom 生成式对话页**：底部对话框 → 访客描述想看什么 → 页面即时重构。引擎（builder/发布助手/视图切换）为**平台给定底座，不展开实现**（参考 `/Users/chenruihua/Documents/Vaults/projects/loom`）。线框 = 重构后页面的**基本形式/默认骨架**，文案数据驱动。
> 流程见 `docs/rh/value-chain-kanban/07-定版-自举开发流程-10分钟.md`；模板见 `docs/rh/value-chain-kanban/06-操作模板库.md` + `00` §五卡模板；persona 见 `P-用户画像-personas.md`。
> **树状结构**：定位 → 北极星 → 输入指标 → **痛点** → 角色(persona) → spec卡 + 原型图。
> **边界**：发起对话 / 对话驱动重构 / 上手体验 = **② Activation**，不在本棒。

## §1 定位稿（定位 → 北极星）

母定位（G-a，源自 `00`）：

> **让被投放或搜到我们的跨境小老板，在划走之前的 3 秒内就看懂「这就是解决我那个问题的东西」，而不必读一屏术语去猜它跟自己有没有关系。**

谁＝被带到站的跨境小老板 / 新体验＝3 秒认出「这是给我的」/ 旧成本＝读术语自猜、划走。AARRR 第 1 棒，交棒 = **有效浏览量**。

## §2 北极星 → 输入指标（指标 + 精确定义）

> **关系**：北极星 = 结果（果）；输入指标 = 能动手推高它的杠杆（因），尽量与北极星成**公式分解**；链条 **痛点→角色→卡 拨动输入指标 → 抬北极星**。
> **公式化到可认领的乘子（原则，见 **`R-修改原则.md`** §1）**：公式里**每个乘子 = 一个输入指标**，每个输入指标都要有「痛点→角色→spec卡」认领，不留无人认领的乘子。

**北极星：有效浏览量** = 统计窗口内「真正看进去」的去重访客数（到站且 停留 ≥ N 秒 或 滚过首屏）。

- `有效浏览量 ≈ 到站量 × 留站率`
- `到站量 = 搜索曝光 × 搜索 CTR ＋ 分享链点击率 × 分享次数`

> **到站量是「各渠道求和」，当前刻意只纳入两条零成本自然流渠道**：自然搜索（①-A1）＋ 分享转发（①-A2/A3 ＋ ⑤ 闭环）。
> **付费投放、直接/线下码、第三方外链/媒体 等暂不纳入**——决策：**先看自然流，不立即做有成本的推广**；待启动付费推广再补。补的时候多是「补公式 + 标主驱动方」而非「补官网卡」：这些渠道主驱动在 **off-site 运营**（买量/PR/线下物料），官网在这些渠道只认领「**落地承接**」（UTM/来源 → persona 变体、落地即命中），而落地承接已由 **loom 底座路由 ＋ ①-B persona 变体** 覆盖（见 `R-修改原则.md` §5）。

| 输入指标 | 精确定义 | 认领卡 |
| --- | --- | --- |
| **A 到站量** · 搜索曝光 | 页面在搜索结果页被展示的次数 | ①-A1 |
| **A 到站量** · 搜索 CTR | 搜索结果点击数 ÷ 曝光数 | ①-A1 |
| **A 到站量** · 分享链点击率 | 带分享来源参数的访问数 ÷ 分享卡展示数 | ①-A2 |
| **A 到站量** · 分享次数 | 官网被转发出去的次数（分享事件数）。**主驱动在 ⑤ Referral（闭环）**；① 只补「进站即转」早期增量 | ①-A3 ＋ ⑤ |
| **B 留站率** · 首屏 3 秒留存率 | 落地后 3 秒内未关闭/跳出的访客数 ÷ 落地访客数 | ①-B1/B2/B5 ＋ B赵/钱/孙 |
| **B 留站率** · 滚过首屏率 | 滚动越过第一屏的访客数 ÷ 落地访客数 | ①-B1/B2/B5 ＋ B赵/钱/孙 |

> **「分享次数」= ⑤ 的转发量产出，在此作为 ① 到站量的乘子回流**——AARRR 首尾相接的形式接点（⑤ ↺ ①，见 `R-修改原则.md` §2「闭环乘子」）。① **不重复造** ⑤ 的转发/激励功能，只补一张「进站即转」早期增量卡 **①-A3**（区别于 ⑤ 的「满意后转」）。
> **发起对话率** 归 **② Activation**（「进站后活跃」的信号，不增加本棒有效浏览量）。
> **实验判读（取代二元 drop）**：每个指标按 `假设 + 窗口 N 天 + 判读{ 达标 T→继续 / 未达→先改方案 / 连续 M 窗口仍未达→drop }`，阈值待运营随上线拍板。

```
└─ 北极星：有效浏览量 (= 到站量 × 留站率)

   │   ├─ 痛点 P2 搜不到我们
   │   │   └─ 角色 全体访客 → 功能卡 ①-A1 搜索可见 · 原型 所有页 meta(无线框)
   │   ├─ 痛点 P3 分享是秃链接
   │   │   └─ 角色 全体访客 → 功能卡 ①-A2 分享卡 OG · 原型 分享卡
   │   └─ 痛点 P3b 进站想转却没入口/没钩子 (拨动 分享次数)

   └─ 输入指标 B · 留站率
       ├─ 痛点 P1 首屏看不懂跟我有关
       │   └─ 角色 全体(基座) → 内容卡 ①-B1主张 / ①-B2结果图 / ①-B5信任 · 原型 默认骨架
       └─ 痛点 P4 看不到「我这一类」

```

> **卡型两类（模板见 **`00`** §五）**：内容卡＝不开发、只调内容；功能卡＝需开发。卡模板是 06 `G-r` 的官网精简版（省略 ICE 打分/价值卡/节点 id）。对话框/builder/发布助手 = loom 底座，引用不重建。
> **persona 视角触发（① 阶段）**：靠**投放/分享落地变体**（loom 变体/底座，无需开发）；无参数落地 → 默认骨架(基座)。对话驱动重构在 ②。
> 原扁平版 `①-B3 场景内容 / ①-B4 痛点镜像` 已**并入各 persona 内容卡**。

### 输入指标 A · 到站量

#### 痛点 P2（G-c）
> 当跨境小老板在搜索引擎找降本提效的办法时，他想找到并对比可信的方案，以便挑一个试；现状受阻于我们的官网在搜索结果里根本不出现，导致这部分人完全接触不到我们。 → 压低**到站量**

##### 角色：全体访客 · 原型：所有页 meta（无线框）

**功能卡 ①-A1 · 搜索可见（SEO 底座）**｜服务痛点 P2｜认领 研发(产品定关键词)
- 用户故事：作为搜「降本/选品 AI 方案」的跨境小老板，我想在搜索结果里看到并点进我们，以便对比方案。
- 范围：只做 默认骨架可抓取性(SSR/预渲染) + 每页 title/description/canonical + 语义化 H + sitemap.xml + robots + Organization/Product 结构化数据；不做 内容营销/外链。
- ⚠ 对话式坑：页面是生成/重构的，**必须 SSR「默认骨架」**，否则爬虫抓到空壳 → SEO=0。
- 验收(G-g)：Given 爬虫抓任一页；When 取首屏 HTML；Then 含真实文案 + meta/结构化数据（非空壳）。
- 优先级：P1
- 挂钩牌：拨动 搜索曝光+CTR / 验证假设「做对 SEO 基建→自然搜索点击爬升」/ 闭环判据 收录页数 + 自然流量 UV
- 产出去向：→ 开 issue 只引本卡

#### 痛点 P3（G-c）
> 当跨境小老板收到同行转发的官网链接时，他想从预览判断这值不值得点开，以便不浪费时间；现状受阻于分享出去只是一条没有标题、没有图的秃链接，导致他直接忽略不点。 → 压低**到站量**

##### 角色：全体访客 · 原型：分享卡

**功能卡 ①-A2 · 分享预览卡（OG 输出）**｜服务痛点 P3｜认领 研发(OG 输出)+设计(封面)
- 用户故事：作为收到转发链接的人，我想光看预览卡就懂值不值得点，以便不浪费时间。
- 范围：只做 每页输出 OG/Twitter meta(标题/描述/封面 URL) 能力 + 各渠道预览实测；不做 个性化分享卡(归 ⑤-A2)。封面图/标题为内容附件(建好后可就地改)。
- 验收(G-g)：Given 贴链接到微信/X；When 生成预览；Then 自定义标题+封面、非秃链接、移动端不裁切关键字。
- 优先级：P1
- 挂钩牌：拨动 分享链点击率 / 验证假设「好预览能把转发变成浏览量」/ 闭环判据 分享链点击率
- 产出去向：→ 开 issue 只引本卡（封面图复用给 ⑤-B1）

#### 痛点 P3b（G-c）
> 当刚进站、被首屏打动但还没深入体验的跨境小老板，想顺手把官网转给可能用得上的同行时，他想有个一键就能转、且转出去对方觉得有用的入口，以便举手之劳推荐；现状受阻于进站阶段根本没有转发入口、也没有「值得转」的钩子，导致这股「刚发现觉得不错」的转发冲动白白流失。 → 压低 **分享次数**（进而压低到站量）

> **边界（闭环乘子，见 **`R-修改原则.md`** §2）**：分享次数的主体（**满意后转发**）在 **⑤ Referral**；本卡只接 ① 独有的「**进站即转**」早期增量，**复用 ⑤-B1／①-A2，不重复造分享组件/激励**。

##### 角色：全体访客 · 原型：进站转发入口

**功能卡 ①-A3 · 进站转发钩子（早期分享）**｜服务痛点 P3b｜认领 研发(复用⑤-B1)+设计(钩子文案)
- 用户故事：作为刚进站被打动的访客，我想一键把官网转给同行、自带好预览，以便顺手推荐、不用复制链接配文。
- 范围：只做 进站视角（首屏/内容区）一个轻量「转给同行」入口（复用 ①-A2 OG 卡 + ⑤-B1 一键分享）+ 一句可转的价值钩子；不做 裂变激励(⑤-B2) / 满意后分享完整机制(⑤)。
- 验收(G-g)：Given 访客在首屏/内容区；When 点「转给同行」；Then 一键带 OG 预览 + ref 参数转出、非秃链接；移动端入口不挤占主张/主 CTA。
- 优先级：P2（① 主战场是「3 秒看懂」，早期分享是增量，不与 ①-B 抢首屏注意力）
- 挂钩牌：拨动 分享次数 → 到站量 / 验证假设「进站早期给入口能薅一波『刚发现就想转』」/ 闭环判据 进站转发入口分享数 + 带回到站量
- 产出去向：→ 开 issue 只引本卡（复用 ①-A2 / ⑤-B1，不新造分享组件）

### 输入指标 B · 留站率

#### 痛点 P1（G-c）
> 当被投放/搜索/转发带到官网首屏时，跨境小老板想在 3 秒内判断「这跟我有没有关系」，以便决定要不要继续看；现状受阻于首屏是术语堆砌和自我夸耀，导致他还没看到与自己相关的东西就划走。 → 拉低**留站率**

##### 角色：全体（基座）· 原型：默认骨架

**内容卡 ①-B1 · 首屏一句话主张**｜服务痛点 P1｜认领 产品(产品负责人对齐定位)
- 信息内容：一句 ≤20 字、直击访客问题的主张（承接 §1）
- 数据来源：定位稿 + 目标人群语言库
- 落位：默认骨架 Hero 顶部
- 候选形式：文字（默认）/ 文字+短视频 / 文字+结果图（形式实验暂缓）
- 验收(G-g)：Given 落地未滚动；When 默认骨架渲染；Then 首屏可见区出现 ≤20 字主张 + 主 CTA。
- 优先级：P0
- 挂钩牌：拨动 首屏3秒留存率 / 验证假设「一句话能拉住人」/ 闭环判据 首屏跳出率 < X%
- 产出去向：→ 内容就地维护（无需开 issue），变更记 changelog

**内容卡 ①-B2 · 首屏结果图**｜服务痛点 P1｜认领 设计+产品(成果数据)
- 信息内容：让访客一眼看懂「长什么样/给什么结果」的视觉
- 数据来源：真实截图/录屏 + 成果数据
- 落位：默认骨架 Hero 视觉位
- 候选形式：截图（默认）/ demo 视频 / 交互 demo / 数据图表（暂缓）
- 验收(G-g)：Given 首屏渲染；When 可见；Then 出现展示真实结果的视觉，移动端等比、弱网降级。
- 优先级：P1
- 挂钩牌：拨动 首屏停留 / 验证假设「结果图比文字更快建立认知」/ 闭环判据 首屏停留 + 滚过率
- 产出去向：→ 内容就地维护（图片/视频替换），变更记 changelog

**内容卡 ①-B5 · 信任素材**｜服务痛点 P1｜认领 运营(供素材)+设计(版式)
- 信息内容：可核实信任信号（数字/客户 logo/证言）
- 数据来源：运营真实数据 / 客户授权
- 落位：默认骨架信任条
- 候选形式：logo 墙 / 数字看板 / 证言轮播（暂缓）
- 验收(G-g)：Given 首屏附近；When 查看；Then ≥1 个真实可核实信任信号；无真实 logo 用数字/证言兜底，不放假 logo。
- 优先级：P2
- 挂钩牌：拨动 首屏3秒留存率 / 验证假设「早给信任锚能压住跳出」/ 闭环判据 含信任条 vs 不含的跳出率
- 产出去向：→ 内容就地维护，变更记 changelog

#### 痛点 P4（G-c）
> 当某一类跨境小老板（如只做选品的）浏览官网时，他想找到「我这一类」的内容对号入座，以便确认这是为他这种情况准备的；现状受阻于页面只有面向所有人的通用介绍，导致他觉得「这不是给我的」而提前离开。 → 拉低**留站率**

> 同一痛点对**多个 persona**成立，各 persona 一套留站内容 + 一个落地变体（原型）。

##### 角色：赵全扛·单干侠（→ personas）· 原型：赵全扛视角

**内容卡 ①-B赵 · 单干侠留站内容**｜服务痛点 P4·P1｜认领 产品 + 运营(供原话)
- 信息内容：他的原话痛点（「我一个人忙不过来、工具拼不动」）+「一套接进来直接跑、不用自己拼」的结果/信任
- 数据来源：运营供该类真实原话 + 产品供「开箱即跑」案例
- 落位：赵全扛视角（默认骨架按此 persona 重构的内容区）
- 候选形式：原话引用 / 短视频证言（暂缓）
- 验收(G-g)：Given 访客落到「单干·全扛」变体；When 渲染；Then 突出「不用自己拼、直接跑」的结果 + 该类原话痛点；不虚构原话。
- 优先级：P1
- 挂钩牌：拨动 留站率(赵) / 验证假设「开箱即跑能留住单干型」/ 闭环判据 赵视角留站率
- 产出去向：→ 内容就地维护，变更记 changelog

##### 角色：钱降本（→ personas）· 原型：钱降本视角

**内容卡 ①-B钱 · 降本派留站内容**｜服务痛点 P4·P1｜认领 产品 + 运营(供 ROI 数据/原话)
- 信息内容：客服人力成本对比 / 降本 ROI + 该类原话痛点（「客服重复劳动、养人贵」）
- 数据来源：运营供真实人力成本/ROI 测算 + 原话
- 落位：钱降本视角内容区
- 候选形式：ROI 对比表 / 数字图表（暂缓）
- 验收(G-g)：Given 访客落到「降本」变体；When 渲染；Then 突出人力 ROI 对比 + 该类原话；数字可核实。
- 优先级：P1
- 挂钩牌：拨动 留站率(钱) / 验证假设「人力 ROI 能留住降本型」/ 闭环判据 钱视角留站率
- 产出去向：→ 内容就地维护，变更记 changelog

##### 角色：孙集成（→ personas）· 原型：孙集成视角

**内容卡 ①-B孙 · 技术控留站内容**｜服务痛点 P4·P1｜认领 产品 + 研发(供技术说明)
- 信息内容：「比你自己搭强在哪」+ 可集成/可靠性说明 + 该类原话痛点（「自搭维护累、不稳」）
- 数据来源：产品/研发供集成方式与对比
- 落位：孙集成视角内容区
