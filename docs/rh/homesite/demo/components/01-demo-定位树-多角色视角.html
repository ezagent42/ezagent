    树读法：北极星 = 果（有效浏览量 ≈ 到站量 × 留站率；到站量 = 搜索曝光×搜索CTR ＋ 分享链点击率×分享次数）；输入指标 = 因（能动手推高的杠杆，公式里每个乘子都要有卡认领）；链条 痛点 → 角色 → 卡 拨动输入指标 → 抬北极星。
    卡型两类：功能卡需开发（开 issue）／内容卡不开发、只调内容（就地维护）。闭环乘子：分享次数主体在 ⑤ Referral，①-A3 只补「进站即转」增量（⑤ ↺ ①）。
    渠道范围：到站量 = 各渠道求和，当前刻意只算两条零成本自然流（搜索+分享）；付费投放/直接/外链等暂不纳入——先看自然流、不立即做有成本推广（点「北极星」节点看详情）。发起对话 / 对话重构 → 归 ② Activation，不在本棒。
