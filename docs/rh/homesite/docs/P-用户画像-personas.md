## 路线乙锚点 persona（靶心三件套：多角色 × 对客公开 × 人工把关）

> **来源**：`08-ezagent价值-一句话讲给别人听.md` §2 产品发现。§2 论证最锋利的两类人**不是**"想用 AI 的电商卖家"（那是 Coze/Dify 已服务的泛人群、落在淘汰线上），而是**同时满足〈多角色协作 + 必须对客户公开 + 需人工把关〉且没工程能力自建底座**的人。下面两个 persona 即这两类的占位假设——**同样未经真实用户验证**，待"用户筛选&验证"流程校准。
>
> ⚠️ **与赵/钱/孙的关系（GTM 张力，悬而未决）**：赵钱孙是 homesite **现行 GTM（路线甲：直接卖跨境电商终端商家）** 的受众，已织进 `V-价值链总表` 约 30 张卡；李/周是 §2 押注的 **路线乙（B2B2C agency + 高风险领域）** 的受众。两条 GTM 是否并行、孰先孰后，是战略级未决问题（见 §2「我赌哪个最锋利」）。**写在此处不代表已切换 GTM**，仅作为待验证假设并列。

### 差异轴（路线乙专用：按靶心三件套切，而非团队规模/成熟度）

| | **李复制**（agency / 数字化服务商） | **周把关**（高风险领域专家 / 咨询个体） |
|---|---|---|
| 一句话 | 给餐饮/教培/电商做私域代运营的小 agency，生意=给很多客户快速搭对客 AI 服务 | 法律/财税/留学/医疗的专家个体或小所，知识值钱但服务不过来，又怕 AI 乱答出事 |
| §2 锐度 | **第一锐度**（B2B2C，我们卖铲子） | **第二锐度**（差异化最硬：人工把关闸门） |
| 真实痛（原话） | "每接一个客户都要重搭一套，养不起这么多人" | "我一个人服务不了这么多客户，又怕 AI 乱答出事" |
| 多角色？ | ✅ 接待→资格判定→出方案→人工接管 | ✅ AI 起草 + 本人复核（+ 助理分诊） |
| 对客公开？ | ✅ 交付物就是给甲方终端用户用的对客页 | ✅ 咨询者凭链接进来咨询 |
| 人工把关？ | ✅ 对甲方负责，AI 出方案需运营复核 | ✅✅ **刚需**：答错要出事，必本人复核后才发（`operator_only→customer_visible`） |
| 团队规模 | 小团队 3–15 | 1–3（个体/小所） |
| AI 成熟度 | 拼过 Coze/Dify 给客户交付，知道单 bot 天花板 | 用过 ChatGPT/GPTs，但不敢直接放给客户 |
| 决策角色 | 创始人/交付负责人，看边际成本/毛利 | 本人，看信任/风险 |
| 想要 | 多租户 + 模板复制生产线，不写代码铺量 | AI 起草 + 把关闸门 + 审计留痕 |
| 主场景 | 给 N 个客户复制对客 AI 服务 | 一对多专业咨询，高风险问答 |

### G-e 零教育成本评估

| 五问 | 李复制 | 周把关 |
|---|---|---|
| 一句话就懂？ | ✅「给你客户搭对客 AI 的流水线」 | ✅「AI 起草、你审完再发给客户」 |
| 已有旧方案？ | ✅ 拿 Coze/Dify 一家家手搭 | ✅ 纯人工 / 不敢用 AI 对客 |
| 知道看 ROI？ | ✅ 算每客户交付工时 / 毛利 | ⚠️ 半 ROI 半风险（服务量×单价 vs 答错代价） |
| 学新心智成本？ | 中（要懂模板 / 多租户） | 低（把关流程贴合现有工作习惯） |
| 替换成本？ | 中（已有 Coze 工作流要迁） | 低（没现成方案敢用，≈ 新增） |
| **锚点判定** | ✅ 痛强、生产线即生意；要证明「复制」比一家家搭省 | ✅ 差异化最硬；门槛在**信任与合规**，不在功能 |

### 淘汰线（什么情况不是路线乙的人）
- **李复制**：只交付单 prompt 机器人、客户不要人工把关也不需复杂对客界面 → Coze 够，不是我们的人。
- **周把关**：客户能接受纯 AI 无人工、或低风险领域（答错不出事）→ 单 GPT 即可，差异化卖点失效。
