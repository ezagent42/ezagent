# T · 内容呈现形式实验（跨切面 track）

> 这是什么：一个**可复用的实验机制**，不属于任何单一 AARRR 棒。
> 官网是 loom 生成式对话页——同一块关键信息可以用**不同载体**呈现（文字 / 图 / 视频 / 树图·图表 / 交互组件 / 对话生成）。「哪种形式效果最好」**不拍脑袋 go/no-go，而是设计成实验**：每种形式 = 一个 loom 变体，跑数据决定 采用 / 改 / drop。
> 各战略定位的「内容卡」在「候选形式(待实验)」字段里**引用本 track 的一个实验实例 `F-<信息块id>`**。

---

## 一、为什么独立成 track（不挂在某个定位下）

- **呈现形式与 AARRR 棒正交**：任何棒、任何关键信息块都可能要试形式，挂在单个定位下会重复。
- **loom 原生支持变体**：视角→发布即变体，可绑受众 / 随机分流（见 `loom-需求总览.md` D4/D7）。形式实验天然落在变体上，零额外机制。

---

## 二、形式选项库

| 形式 | 适合 | 成本 |
|---|---|---|
| 文字 | 精确、可被搜索引擎索引（SEO） | 低 |
| 图 / 截图 | 一眼看结果 | 低 |
| 视频 | 流程 / 情绪 / 演示 | 高（制作） |
| 树图 / 图表 | 结构 / 对比 / 数据 | 中 |
| 交互组件 | 让人动手（试用感） | 中–高 |
| 对话生成 | 千人千面、即时相关 | 底座给定（loom） |

---

## 三、实验设计模板（每个形式实验实例填一份）

```
实验 F-<信息块id>：
- 信息块：<哪块关键信息>（来自哪张内容卡）
- 假设：用<形式X> 比 <形式Y> 更能 <提升该块的局部指标>
- 变体：<形式A> / <形式B> / …（各 = 一个 loom 变体）
- 局部指标：<该信息块的局部转化：停留 / 理解 / 点击 / 继续对话 / 到达下一棒>
- 窗口 / 样本：N 天 或 M 次曝光
- 判读：达标 → 采用该形式
        未达 → 换形式 或 改内容（不是直接砍）
        全部形式皆不达 → drop 该信息块
```

---

## 四、与接力链的接法

- 内容卡的「候选形式(待实验)」= 指向一个 `F-` 实例。
- 实验结论的回收 = 接力链 ⑨→② 闭环的一部分（实测决定 继续 / 改 / drop）。
