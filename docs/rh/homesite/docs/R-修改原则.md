## §1 指标公式化到「可认领的乘子」

**触发**：写 §2「北极星 → 输入指标」时。

**原则**：北极星不止**列举**输入指标，要尽量写成**公式**（× / ＋）；公式里**每个乘子 = 一个输入指标**；每个输入指标都必须有「痛点 → 角色 → spec卡」认领——**不留无人认领的乘子**。

**例（①）**：
- 一级：`有效浏览量 ≈ 到站量 × 留站率`
- 二级：`到站量 = 搜索曝光 × 搜索 CTR ＋ 分享链点击率 × 分享次数`
- → 「分享次数」既然是乘子，就**必须**有自己的痛点（P3b）和 spec卡（①-A3），不能只当背景词。

**怎么落**：
- §2 表加「**认领卡**」列，指标 ↔ 卡可追溯。
- 自检：公式里每个符号，都能在 §2 表里找到一行、在 §3 树里找到一个痛点、在「附·卡速查」找到一张卡。三处对不齐 = 漏了认领。
- 能二级分解就分解（如 到站量 = 搜索 ＋ 分享），别停在一级。

## §2 闭环乘子（跨棒指标）：闭环引用 ＋ 本棒最小认领

**触发**：公式里某个乘子**主要由别的棒驱动**。典型：① 到站量里的「分享次数」其实是 ⑤ Referral 的「转发量」产出。

**原则**：**不重复造别棒的功能**。用「**闭环引用 ＋ 本棒最小认领**」三步：
1. **标注主驱动棒**（分享次数主体在 ⑤）；
2. 本棒只补一张**本棒独有角度**的卡——① 的「**进站即转**」早期分享，区别于 ⑤ 的「**满意后转**」；
3. **复用对方已有 spec**（①-A3 复用 ⑤-B1／①-A2），范围里明写「不做对方已做的部分（裂变激励/满意后机制）」。

**意义**：AARRR 首尾相接的形式接点，就落在这些闭环乘子上（⑤ ↺ ①）。同一个指标在两棒各有一段、对应漏斗不同阶段，不是重复。

## §3 痛点编号增补：字母后缀，不级联重排

**触发**：全局痛点 P1–P25 已定，后期要在中间插新痛点。

**原则**：新痛点用**字母后缀**就近挂（如 `P3b` 挂在 P3 旁，都属「分享」族），**不重排**后面所有编号。后缀痛点在速查表里紧跟母编号。

---

## §4 复用记账

**触发**：一张卡复用另一张卡的能力。

**原则**：在「范围 / 挂钩牌 / 产出去向」明写复用关系（如 ①-A3 复用 ⑤-B1）；复用链要**无环或可解释**（①-A2 → ⑤-B1 → ①-A3 是一条单向链，OK）。避免两棒各造一个一键分享。

## §5 「入口」型指标 ＝ Σ渠道，每渠道标主驱动方（含 on/off-site 切分）

**触发**：某输入指标是「入口/到达」类（如 ① 到站量、⑤ 带回的到站、② 发起对话的来源）。

**原则**：
1. 入口型指标本质是**各渠道求和**：`到站量 = Σ 渠道`（投放、自然搜索、分享、直接/线下码、第三方外链…）。
2. **每个渠道标「主驱动方」**：`官网 spec` / `off-site 运营`（买量/PR/线下物料）/ `loom 底座承接`。
3. **off-site 渠道，官网只认领「落地承接」**——UTM/来源 → persona 变体、落地即命中。落地承接通常**已被 loom 底座路由 ＋ persona 变体卡覆盖**，所以补渠道多是「**补公式 + 标 owner**」，不是「补一堆官网卡」。
4. **可按阶段只纳入部分渠道，但要记原因**：① 当前只纳入「自然搜索 + 分享」两条**零成本自然流**，**付费投放等有成本渠道暂不纳入**——原因「先看自然流、不立即做有成本推广」**写在文档里**，留好以后补的口子（别让公式看起来已穷尽）。

**例（①）**：母定位说「被投放或搜到」，但投放主驱动在 off-site 运营；当前先不做付费推广 → 公式只列自然流两渠道 + 一句「暂不纳入投放/直接/外链，先看自然流」的说明。
