## 三、怎么找 + 给我什么格式（按"我能吃进去且最有用"排序）

1. **书的相关章节 PDF / 截图**（最佳）。我有 `pdf` skill 能读，**给对应章节就行，别整本**。认准上表"关键概念"那几页。

3. **权威长文链接**（也行）。我能 WebFetch。俞军内容中文长文质量参差，优先：得到《俞军的产品方法论》课程笔记、微信读书/京东读书书摘、知乎高赞拆解、B站精读。
