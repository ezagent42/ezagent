2. loom
  1. 内嵌的浏览器窗口（preview）没有返回和前进按钮，用户一边用v0创建一边试玩的过程中，如果跳转了就无法回退。目前想不清回退是回到上一个页面还是回到上一段prompt，所以先不做。
  2. 先输入消息后添加附件，消息就清空了，需要重新输入
  3. 对话区域：
    1. 每次都要艾特v0，可以考虑是否可以默认就是艾特V0的，不需要手动艾特。
    2. 编辑者翻看之前的对话记录时，新消息弹出导致编辑者又回到了最新消息，需要重新往回翻。
    3. 编辑者翻看之前的对话记录时，想要快捷回到最新消息，目前没有支持一键回到最新消息的按钮。
    4. 复制已经发送的消息。
    5. 过长的消息可以折叠。
  4. 急需上传附件，比如html
