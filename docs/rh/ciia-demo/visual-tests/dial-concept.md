## 几何模型（用户修正版）

**圆心**：屏幕正下方外侧（off-screen），固定不动。
**半径**：极大——屏幕只是裁切显示了圆弧顶部的一小段。
**扇区**：N 个等角扇区，从圆心向上辐射，屏幕范围内每个扇区几乎覆盖全屏。

### 理解关键

Logo 和 Dialog **不在同一水平线上**：
- **Logo**：离圆心最近 → 屏幕左下角（贴近底边）
- **Dialog**：离圆心更远（半径中点）→ 屏幕底部中间，但**比 Logo 高**
- **内容区**：扇区上部 → 填充屏幕中上部

### 半径关系

```
圆心 O（off-screen，正下方）
  │
  │  r_logo   → ●  屏幕左下角（离圆心最近）
  │
  │  r_dialog → ▄  屏幕底部中间（比 logo 高，半径中点）
  │
  │  r_content→ □  屏幕中上部（产品网格/表单等）
  │
  │  r_edge   → →  扇区顶部边缘（超出屏幕上边界）
```

Logo 最靠下（半径最短），Dialog 在半径中点（更高），内容区填满扇区上部。

### 旋转交互

```
右侧上下拖拽/滚轮
  → 拨盘绕圆心旋转
  → 下一个扇区转进活跃位置
  → Logo 和 Dialog 固定在原位，但内容切换为下一个 socialware
```

Logo 和 Dialog 的屏幕位置不变——旋转只是换了"哪个扇区"的内容出现在这些位置。
