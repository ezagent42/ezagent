## 1. 现有网站结构

### 全称与定位

**中国信息协会数据智能专业委员会**（CIIA Data Intelligence Committee），2025 年 9 月 28 日成立。
定位："数据智能公共服务平台"——围绕 "数据要素 ×" 与 "人工智能 +"，提供智库咨询、资产评估、数据流通、人才培养与会展生态的综合公共服务平台。

### 页面树

```
ciia-dipc.com
├── /                         首页（活动 + 动态 + 会员名录 + 成果数据）
├── /about                    关于我们（协会介绍 + 组织结构 + 会员名录 + 联系方式）
├── /news                     新闻资讯
├── /site-monitoring          站点监测（要闻聚焦 / 通知公告 / 近期活动预告）
│   └── ?articleId=N          文章详情页（4 篇）
└── /services/
    ├── /think-tank           智库咨询（行业报告 / 白皮书 / 期刊论文）
    ├── /training             人才培养（高管研修班 / 大模型训练营）
    ├── /assessment           评估服务（智能体管理成熟度评估 T/CIIA 070-2026）
    ├── /expo                 会展活动（数字中国峰会 / 世界人工智能大会分论坛）
    └── /public-package       公共服务（AI 安全治理 / 安全测评 / 行业应用）
```

### 导航结构

**一级导航**：首页 / 智库咨询 / 人才培养 / 评估服务 / 会展活动 / 公共服务 / 关于我们

**无二级导航** — 当前网站是扁平结构，所有服务页同级。

## 6. 从 CIIA 网站发现的关键洞察

### 洞察 1：CIIA 网站本质上是一个"内容陈列柜"

当前网站 = 静态页面 + 服务介绍 + 新闻列表 + 会员名录轮播。
**没有任何交互功能**——不能搜索、不能联系、不能申请、不能评估。
"在线客服"只是右下角一个图标占位，没有实际对话能力。

→ **我们的平台恰好补上了这整个交互层**：搜索/Session/Agent/表单/审批。

### 洞察 2：会员名录是产品展厅的天然 seed data

CIIA 已有 ~50 家会员企业名单（含高校和研究院）。
这些企业的"产品"目前不在 CIIA 网站上——只有企业名称。
我们可以用这 50 家企业初始化产品展厅，每家一个占位产品（"该公司尚未录入产品 · 点击催促"）。

→ 这个设计一举两得：展厅不空 + 倒逼会员来录入。

### 洞察 3：CIIA 有"在线客服"意图，但无实现

右下角"在线客服"图标存在但不可用。
这说明 CIIA 自己也知道需要在线对话能力——这正是 Session + Agent 的切入点。

→ "在线客服"图标可以直接换成"💬 联系协会 · 由 ezagent 驱动"。

### 洞察 4：评估服务是 CIIA 的差异化壁垒

CIIA 有自研标准 T/CIIA 070-2026（智能体管理成熟度评估模型）。
这是 CIIA 的独家资产，其他协会没有。我们的平台上应该把这个评估做成**在线可用的服务**——企业在线申请评估 → Agent 引导流程 → 评估报告 → Session 跟踪。

→ 评估服务是 ezagent 展示"Agent + 流程自动化"能力的最佳场景。

### 洞察 5：扁平导航不够——需要角色分层

CIIA 现有 5 个服务 + 关于我们 = 6 个一级导航项，全是同级的。
没有区分"给谁看的"。访客、会员、内部人士看到的是同一套导航。

→ 我们的平台应该有**角色感知的导航**：访客看公开内容 → 会员登录后多出"会员专区" → 管理员多出"管理后台"。
